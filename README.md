# OPAL-OKB — САПР оптики

> Портирование расчётного ядра **OPAL-PC** (MS-DOS, 1990-е) на **Python 3.10+ / PyQt5**, разработанное коллективом под руководством Родионова Сергея Ароновича

Расчёт, анализ, оптимизация и визуализация оптических систем: линз, объективов, окуляров, зеркально-линзовых систем.

## Установка и запуск

```bash
pip install PyQt5 numpy
py main.py
```

- **Python 3.10+** (рекомендуется 3.13)
- На Windows используется `py` launcher

## Возможности

### Расчёт
- **Параксиальный расчёт** — y-nu метод: f', BFD, FFD, кардинальные точки
- **Суммы Зейделя** SI–SV: сферическая, кома, астигматизм, кривизна поля, дисторсия
- **Реальная трассировка лучей** — векторный закон Снеллиуса, TIR, OPL
- **Пространственные системы** — наклон X/Y/Z (°) и децентрировка X/Y (мм)
  поверхностей: точная трассировка в локальной СК поверхности (матрица
  поворота + смещение вершины), NaN-безопасность (луч мимо поверхности —
  маркер «пропал», без крэша)
- **Асферические поверхности** — конические (k) + полиномиальные A4–A10
- **Многоволновый расчёт** — до 5 длин волн одновременно

### Каталог стёкол
- **891 марка**: ГОСТ (14 базовых + КВАРЦ/КВАРЦСТК/ОФ1/ТК20) + Schott + HOYA + Ohara
- Формула Герцбергера для n(λ)
- **n_override** — точные показатели преломления из LBO-файлов OPAL-PC

### Библиотека оптических систем
- **612 систем** в 13 библиотеках (.LBO):
  - LENS (116) — объективы (Индустар, Юпитер, Мир)
  - OCULAR (76) — окуляры
  - RUSSAR (84) — широкоугольные объективы
  - BINOCUL (22) — бинокли
  - и др.
- **Декодер LBO** — полное reverse engineering бинарного формата:
  - Все поля заголовка расшифрованы (см. `docs/LBO_FORMAT.md`)
  - Поддержка зеркал (glass_index=65535)
  - Glass names: smart split (КВАРЦСТК, склеенные имена)
  - Тип предмета/изображения, апертура (NA/Y/F#), диафрагма (ND+SD)
  - Стандартные длины волн e, G', C по умолчанию

### Поддержка зеркал
- Зеркально-линзовые системы (катадиоптрические)
- Визуализация: золотистый контур + штриховка отражающей стороны
- `paraxial_trace()`: n sign flip + reflection formula
- `seidel_aberrations()`: mirror-aware

### Параксиальные характеристики
- Мульти-λ таблица: f', sF', Δf' для каждой длины волны
- Кардинальные отрезки: sF, sF', sH, sH', sP, sP'
- Единицы зрачков мм/дптр: положения зрачков sP/sP' и оси поля (переключатель на панели анализа и результатов; 1 дптр = 1/м, поле — tan-конверсией через f')
- Г.ММСС формат угловых полей
- **Число Штреля** (строка под суммами Зейделя): Марешаль
  S = exp(−(2πσ)²) и точный FFT-PSF (пик аберрированной системы /
  дифракционный предел); полихроматическое взвешенное среднее по λ,
  tooltip с формулой, точным значением и разбивкой по λ

### Формирование оптической системы
- Тип предмета/изображения: дальнего/ближнего типа
- Передний отрезок, смещение от пл. Гаусса (мм/дптр)
- Диафрагма: ND (поверхность) + SD (смещение)
- Передняя/задняя апертура: Y/NA/F/#

**OPAL-таблицы** (реверс OPAL-PC, `analysis/tables.py`, REVERSE_TRACE.md §15):
TABGL «Характеристики главных лучей пучков» (эталон RT__2250.PRN — формат
байт-в-байт) и TABPR2 «Хроматизм увеличения/положения» — по зонам поля
1/.816/.577: дисторсия, Z'm/Z's, C'm/C's, хроматизм увеличения/положения
на второй λ. Углы — в мере OPAL «гр.мнсек» (градусы + минуты/100).
Печатаются в протоколе расчёта при поле > 0.

**Таблицы осевого пучка + система единиц OPAL** (реверс §11+§19,
`analysis/tables.py` + `analysis/units.py`, эталон RT__2236.PRN):
TABOC1 «Отн.зр│ Продольные (мм)│ Поперечные (мм)» и TABOC2
«Tg'*100│ Волновые (дл. волн)│ Неизопл. (%)│ Н ЗР (мм)│ Z'm│ C's» —
по зонам зрачка равной площади 1/.866/.707/.5 + осевая; селектор колонок
TABOC2 (3 из 5 величин, ветвление [0x34b8]). «Н ЗР» расшифровано (§19.1):
H ЗР = входная зрачковая координата луча в мм = зона × Ax (эталон — точно
до 4-го знака). `analysis/units.py` — единицы «ближний/дальний тип»:
мм↔дптр, «гр.мнсек» (f12.6, «-36.000000»), tg×100/tg'×100, H ЗР/H' ЗР.
Печатаются в протоколе расчёта всегда при наличии поверхностей.

**Виньетирование и светораспределение** (реверс §14/§17.6,
`analysis/vignetting.py`): TABBEA «Апертуры │ Положение зрачков │
Виньетир. │ Светораспред │ Ограничения» — по полям: Ax/Ay/Ax'/Ay',
Sp/Sp', виньетирование верх/низ (меридиональный веер, % срезанного края
зрачка), светораспределение (доля площади зоны прохождения на входном
зрачке от осевого пучка; с центральным экранированием — 1−ε²),
ограничивающие элементы 2×(буква+N): D диафрагма / P поверхность /
M зеркало-экран. Закрывает вычислительный пробел №1 порта
(REVERSE_0746.md §17.6).

**Световые высоты и экранные зоны** (реверс §14.1,
`analysis/beam_heights.py`): TABESB «Световые высоты» — высоты Y
габаритных лучей на каждой поверхности (формат
`(1X,i3,f11.3,2f12.3,4f10.3)` + строка «─ Длина волны - N»): осевой
крайний, верхний/нижний предельные (край зрачка ±Ay), верхн./нижн.
рабочие (границы зоны прохождения с виньетированием) и
верхн./нижн. отверстия (±semi_diameter); TABEAP «Экранные зоны» —
экранирование зеркально-линзовых систем: относительные размеры экрана
x/y на входном/выходном зрачке, смещение эллипса на экране,
виньетирование и «Ограничения» (буквы и числа — единые с TABBEA:
`vignetting.compute_vignetting`).

**ФРТ/ФРЛ/ОПФ/ФКЭ — уровень-2 анализа** (ANALIZE.DOC §9, работа DIA,
`analysis/psf_mtf.py`): дифракционные характеристики изображения по
**Золотая верификация против OPAL** (сверка с DOSBox-эталонами 14 систем,
досье REVERSE_GVERIFY/GFIX/OPALDIS): \nalysis/golden_verify.py\ — харнесс
сверки (парсер .PRN/OPJ, веера, допуски); \ileio/standalone_opj.py\ — строгий
загрузчик standalone-OPJ (предмет f64@0x4C, диафрагма ND/SD, ГОЭ 0xFFFD →
\SurfaceType.HOLOGRAM\ с κ(λ)-законом); зрачки z/d/p, ближний предмет, мнимые
изображения, кромки и λ-закон печати — в \berrations.py\/\domain/calculations.py\.

стандартной физике. ФРТ = |FFT(W-зрачок)|² с амплитудой чистой апертуры
(центральное экранирование зеркальных систем учитывается) и параметром
дефокусировки; координаты плоскости изображения в мкм (шаг
δ = λf′/(M·Δξ), срез ν_c = D/(λf′)). ФРЛ — интегралы ФРТ по осям
(меридиональная/сагиттальная, терминология OPAL §9.4); ЧКХ =
|FFT(ФРТ)| с сечениями меридиональным (ν вдоль Y) и сагиттальным;
ФКЭ — кумулятивная энергия в круге от энергетического центра; Штрель —
пик ФРТ/пик идеала (масштаб — коэффициент заполнения зрачка, сверка с
`strehl.py` в тестах до 1e-3); синус- и шпальные миры — свёртка с ФРЛ,
контраст синус-миры на частоте ν равен MTF(ν). Краткая секция «ФРТ/ОПФ»
печатается в протоколе расчёта; сверка с OPAL-алгоритмами — реверс-волна 10.

### Визуализация
- Ход лучей в стиле OPAL-PC (чёрный фон, зелёные лучи, голубые линзы)
- **Хроматические лучи** — кнопка «Хром.Ц»: все длины волн разными цветами
- Зум (колесо мыши), пан (drag), крестокурс с координатами
- Полноэкранный режим (двойной клик)
- Таблица лучей

### Оптимизация
- **DLS** (Damped Least Squares)
- **Nelder-Mead Simplex**
- **ЛАП/GTISL** (`analysis/optimization.py`, волна 9 — реверс OPALLAP):
  многоцелевой МНК по досье REVERSE_LAP §9 — якобиан центральными
  разностями P±DP0, масштабирование столбцов GTIMAS, нормальные
  уравнения Марквардта (JᵀJ+λ·diag)ΔP = −Jᵀ·оф, лимитер шага 10·DP0,
  до 15 бисекций линейного поиска, λ-адаптация, istop-коды OPAL
  (0/1/2/−1); границы pmin/pmax — штрафами (не молчаливый clamp),
  связи переменных Δведомый = k·Δведущий, solve-режим 1×1 с явной
  ошибкой «параметр не влияет»; цели — f′/BFD/V, продольная/поперечная
  аберрации по зонам/полям, RMS пятна, суммы Зейделя, астигматизм/кома/
  дисторсия; входной язык OPAL (PAR/EQF/MF + pmin/pmax + D</DE</AS<…)
  — `parse_opt_file` (проверено на extracted PLIOPT.OPT)

### Подгонка характеристик
- f', BFD — solve-режим ЛАП (Ньютон по центрально-разностной
  чувствительности; бисекция optimizer.fit_* сохранена для API)
- Любая цель × любой параметр (f' толщиной, BFD радиусом — тоже можно)
- Умные дефолты: цель автозаполняется текущим значением характеристики
- Толщина последней поверхности (до плоскости изображения) исключена;
  зеркало + толщина — tooltip-предупреждение
- Подтверждение «Применить/Отмена» с показом старое→новое до применения
- Вкладка «Оптимизация (ЛАП)»: чекбоксы переменных по поверхностям
  (R/d/e²/SD), границы по типам, список целей с весами/зонами/полями,
  max_iter/damping; прогресс в статусбаре, протокол GTISL в подтверждении

### Ахроматизация
- Автоматический расчёт R для пар стёкол (крон + флинт)

### Импорт / Экспорт
- **.OPJ** — файлы OPAL-PC (standalone + из LBO-библиотек)
- **.opal.json** — человекочитаемый JSON
- **Протокол расчёта (.txt)** — параксиальные характеристики, суммы
  Зейделя, таблица поверхностей + OPAL-таблицы TABGL/TABPR2 (при поле > 0)
  + секция ФРТ/ОПФ (Штрель FFT, срез, ЧКХ мер/саг)

### Системные операции
- Оборачивание (reverse)
- Масштабирование
- Стандартные радиусы ГОСТ 1807-75 (ряд R40)

### Многопоточный расчёт
- **Фаза 1** (мгновенно): параксиальный расчёт + ход лучей
- **Фаза 2** (фон): все вкладки анализа параллельно (до 8 потоков)
- Индикатор «⏳ Расчёт...» во время вычислений
