## СУТЬ ПУНКТА
Поддержка децентрировки/наклона поверхностей:
- decenter X/Y (смещение вершины, мм), tilt X/Y/Z (в градусах)
- Трассировка лучей через наклонённые/смещённые поверхности:
  матрица поворота + смещение вершины, пересечение с поверхностью
  итерационно (метод Ньютона) для асферик, аналитически для сфер если возможно
- Таблица конструктивных параметров в UI: колонки наклон/децентр
  (проверь: парсер LBO/OPJ уже читает эти поля? если да — подключить,
  если нет — добавить в модель и парсер)
- Логика в domain/ (raytrace, модель поверхности), UI только отображает

## МИНИМАЛЬНАЯ ВЕРСИЯ (если полный объём слишком велик)
Tilt/decenter вокруг осей для сфер + плоскостей:
- golden test: параллельная пластина с наклоном = эквивалент призмы
  (луч смещается и отклоняется предсказуемо)
- тест: система из двух поверхностей с наклоном, сравнение с ручным расчётом
- NaN-безопасность: лучи мимо поверхности → маркер «пропал», не крэш
