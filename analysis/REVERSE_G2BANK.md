# G2BANK — банк эталонных .PRN (волна 2026-10-17)

**Цель:** 10–15 систем разных типов из каталога `C:\GOLDEN_DOS` (*.OPJ, 82 имён —
тот самый «каталог архива» файлового диалога Чтения) → эталонные .PRN по проверенному
рецепту TASK_G2BANK / G2_NOTES §«ЗОЛОТОЙ .PRN»:

```
boot → ENTER(Работа-RT) → F10 → ENTER(Сист→METAPRN) → F2 ENTER(Чтение)
→ BS×12 <ИМЯ> ENTER → F10 → RIGHT RIGHT ENTER(Анализ) ENTER(Работа-RT)
→ '4' → '6' → F4 → F9 → ENTER → RT__HHMM.PRN → bank/<ИМЯ>.PRN
```

Оракулы: заголовок окна DOSBox (`Program: …`), `PROTOCOL.PRN` 0 б (свежесть),
контент .PRN (заголовок «Cистема-…», секция «Аберрации осевого пучка»).
Драйвер: `scripts/g2bank.py` (`py scripts/g2bank.py ИМЯ [ИМЯ…]`).
Артефакты: `analysis/reverse_data/golden/bank/`, скрины `capture/gb_*.bmp`.
