## Модель UI (эмпирика, обновлённая)

- MENUOPAL верхний бар после СВЕЖЕГО старта НЕ активен: ENTER по «Сист» игнорируется.
  Активируется после первого прохода через любую работу (F5 → Работа-RT → F10).
- В Работа-RT: цифры 1–9 выбирают И ВЫПОЛНЯЮТ пункт меню; ENTER выполняет
  подсвеченный; SPACE ничего; ESC из VIEW-состояния возвращает в меню.
  Аберрационные пункты (6,7) НЕ выполняются, пока не посчитаны габариты (пункт 4):
  «Определение габаритов пучков производится всегда перед вычислением аберраций»
  (ANALIZE.txt §4.3) — до этого ENTER молча игнорируется.
- Параксиальные (п.2) работают всегда. Форма вывода TEXT/GRAF — F6; инфо-строка
  показывает «TEXT-5» (текст в окно 5), состояние MENU/VIEW/EDIT/CALC.
- Меню «Печать» (F7 из Работа-RT, состояние меню): 1 Экран / 2 Расчет /
  3 Протокол / 4 Таблица / 5 ДТА / 6 Установки / 7 Выход.
- Протокол (F4): копит ВСЕ выведенные таблицы; подсказки Выбор-ENTER, Full-F5,
  Print-F6, Save-F9 (в моих сессиях F4-окно на клавиши не реагировало).

## Побочные находки форматов

- **OPAL.ARH**: «Чтение» (загрузка US00KI02) ОБНОВИЛА архив (mtime, размер
  21734 б) — загрузка не есть чистое чтение, каталог/слоты трогаются.
- Файл **TMP$7** (582 б, двоичный, float-подобный мусор) — временный от работ.
- RT.REG = `GAB=4;WING=0;WINT=0;GR;` (графформа на старте), PRINTER.REG = `pin=0;title;`.
- Файловый диалог архива: F5=Time, F6=Full, F8=Delete, F9=Filter (подтверждено).
- Редактор (METAPRN): F2-Меню → Файл(Чтение F9/Запись F8/Входной язык/Новая/
  Присоединение/Печать/Установить путь в архив/Библиотека), F7-Отметка (НЕ жать
  вслепую — цифры попадают в таблицу и правят систему!).
