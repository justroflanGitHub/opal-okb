## P1 — диафрагмы 'z'/'d' в paraxial_trace (коммит fix(domain))

**Семантика OPJ (реверс заголовка, валидирован эталонами)**:
- `0x3A` = ND (u16) — 1-индексация поверхности диафрагмы;
- `0x6C` = SD (f64) — смещение плоскости от вершины поверхности ND;
- плоскость диафрагмы `z_stop = вершина(ND−1, 0-based) + SD` —
  едина для ВСЕХ значений `0x46` ('d'/'z'/'p' — только способ ввода
  в UI; OPAL.DOC: «ND=кол-во поверхностей до диафрагмы, SD=0 —
  совпадает с поверхностью»);
- SD=0 → диафрагма НА поверхности: клиппинг делает полудиаметр
  самой поверхности, отдельная плоскость не строится.

Подтверждение зрачков (sP/sP′, Δ<5e-5): KURSOVIK 'z' (−59.976/
23.835 мм), ST 'z' (26.668 мм/−7.181 дптр), HELIOS8 'd' (24.134/
−15.297 дптр), 121 'p' (14.444/−1.986 дптр), US00KI02 'p' (−22.2/
−147.67 мм).

**Конвенция печати Sp′ (габаритная таблица)**: ближнее изображение
(img=1) — дптр от плоскости Гаусса `1000/(sP′−bfd)` (HELIOS8/ST/121
— 4 знака); дальнее (img=0) — мм от последней поверхности
(US00KI02/KURSOVIK).

### Изменения порта

1. `domain/calculations.py::paraxial_trace` — зрачки через главный
   луч (линейная комбинация базисных (1,0)/(0,1) через плоскость
   диафрагмы); прежняя обратная трассировка теряла преломление на
   диафрагменной поверхности и SD (до 40 % на HELIOS8).
   Границы пространства: полуинтервал (z_k, z_k+d_k] — плоскость на
   вершине поверхности принадлежит пространству ДО её преломления;
   z_stop ≤ 0 — предметное пространство (диафрагма на первой
   поверхности: входной зрачок в самой плоскости).
2. `analysis/ray_tracing.py` + `ray_native.py::_system_params` —
   z_stop по той же формуле (был off-by-one на поверхность);
   синхронно guard SD=0 (плоскость на вершине поверхности отключает
   отдельную стоп-проверку; иначе фантомная стоп-точка сдвигает
   начало луча и меняет ветви пересечения downstream — Кассегрен).
3. `analysis/beam_heights.py` (2 места), `analysis/vignetting.py`,
   `gui/analysis_panel.py::_gauge_point_labels`, `visualization3d.py`
   — та же формула z_stop (off-by-one везде).
4. `analysis/golden_verify.py` — юниты габаритной строки
   (`(мм)/(дптр)`), дптр-конверсия Sp′, Ax из max Н ЗР → габарит →
   апертура OPJ; λ-матчинг gabarit ±2e-3 (OPJ f32);
   абсолютные шумовые пороги вердиктов (прод 2e-3 мм / 2e-4 дптр,
   волновые 1e-3 мкм): PRN печатает 5 знаков, n порта/OPAL идут из
   f32-λ — систематика ~1e-3 мм неустранима; у нулей сферической
   аберрации (OPAL3 з.0.866: 0.046 мм при |Δ| 1 мкм) чистое
   |Δ|/|OPAL| взрывается и RED обвиняет ложно. Порог волновых 1e-3
   мкм выбран НЕ глотать систематику опорной сферы ~2 % (§2.4).

## P2 — терминальная толщина трейсера (коммит fix(analysis))

**Диагноз §4.1**: при нулевой терминальной толщине путь кончался
сегментом ДО преломления на последней поверхности (наклон осевого
веера −0.090923 вместо пост-рефракции) — все потребители направления
берут конечную разность path[-2]→path[-1] (осевой веер, волновые,
дифракция). Харнесс обходил заглушкой `_IMAGE_EPS=1e-3`.

**Фикс**: терминальный сегмент строится ВСЕГДА (кроме |m|≈0):
- `analysis/ray_tracing.py` — при нулевой терминальной толщине сегмент
  длиной `TERMINAL_EXIT_EPS=1e-3` ПО ХОДУ луча (знак по m: свёрнутые
  зеркальные системы выходят в −z) до плоскости вершины — точка у
  плоскости вершины, эталон-валидированная геометрия продольных
  (L = −y/slope от этой плоскости, §2.2);
- `native/src/raytrace.cpp` — ядро детектит нулевую толщину по
  совпадению img_z с вершиной последней поверхности и строит тот же
  ориентированный сегмент (`TERMINAL_EXIT_EPS` синхронизирован
  константой); `.pyd` пересобран; `ray_native._system_params` —
  `propagate_to_image` всегда, без пред-сдвига;
- `analysis/aberrations.py::_air_exit_direction` — терминальная точка
  (≤ TERMINAL_EXIT_EPS от плоскости изображения) считается достигнутой
  плоскостью: прежний допуск EPSILON=1e-10 пропускал её в ветку
  «путь оборвался» и ДО-преломлял направление по Снеллиусу второй раз;
- `analysis/golden_verify.py` — `_IMAGE_EPS` удалён, маркер 1e20 →
  толщина 0.0 (обход больше не нужен, no-op).

Наклон сегмента точен при любой длине (луч прямой) — значения
прод/волновых эталонных систем бит-в-бит прежние: **G94/Y6/R12/S48
без изменений**, US00KI02 G18 Y1 R2 (sanity зелёная).

## P3 — compute_isoplanatism KeyError (коммит fix(analysis))

**Диагноз §4.3**: интерполяция высоты главного луча брала сетку из
веера поля ε (`sorted(by_pupil_eps.keys())`), а значения дёргала из
осевого веера — высоты, виньетированные только в осевом веере, давали
KeyError (LAB6_GAS: 0.4737; 121: −1.0 — исчез после унификации стопа
P1).

**Фикс**: `aberrations.py::compute_isoplanatism` — сетка интерполяции
`sorted(common)` (общие высоты двух вееров; они же идут в выходные
`pupils` — возрастание для `_interp_at` сохранено). LAB6_GAS теперь
даёт 6 общих точек (≥ ISO_MIN_RAYS), 121/US00KI02/OPAL3 — полные 20.

Regression: `test_golden_verify::test_isoplanatism_vignetted_fans_
no_keyerror[121|LAB6_GAS]` — без исключения, сетка возрастает,
значения конечны. Полный pytest 1108 passed; вердикты харнесса не
меняются (iso LAB6_GAS в сравнении не участвует — строки системы
SKIP по ближнему предмету).

## P4 — опорная сфера волновых (§2.4, коммит fix(analysis))

**Диагноз**: OPAL строит опорную сферу волновых аберраций не от
последней поверхности: центр = параксиальное изображение (как в
порту), но вершина — центр выходного зрачка. Прежняя сфера с вершиной
на последней поверхности отстояла от OPAL-евой на sP′ — систематика
2–3 % во всех зонах (US00KI02 0.7779/0.3691 против 0.7532/0.362).

**Фикс**: `aberrations.py::_reference_sphere` — вершина
`z_exit = last_surf_z + sP′` (sP′ из paraxial_trace), радиус
R = |cz − z_exit|. Эксперимент US00KI02 (bfd −4411.31, sP′ −147.6695,
cz −3917.85 → z_exit 345.79, R 4263.642): 0.75315/0.36191/0.13527/
0.027884 по зонам 1.0/0.866/0.707/0.5 против эталона
0.7532/0.362/0.1354/0.0279 — ≤0.03 % (цель карточки ≤0.5 %).
Fallback: вырожденный/отсутствующий зрачок (|cz − z_exit| < ε) —
вершина на последней поверхности (прежняя опора, синтетика тестов).

**Вердикты после P4: G103/Y5/R4/S48** (было 94/6/12/48). По системам:
US00KI02 **G21 Y0 R0** (полностью зелёная, sanity), OPAL3 G19 Y0 R0,
HELIOS8 G20 Y1 R0, KURSOVIK G18 Y2 R1, 121 G16 Y2 R3, ST G9 Y0 R0.

## P5 — строгий парсер standalone-OPJ — вход порта (коммит fix(fileio))

**Диагноз §4.4**: строгий парсер (раскладка, валидированная банком
.PRN) жил только в харнессе; порт грузил standalone .OPJ эвристиками
(opj_io R,d-интерлив + decode_lbo со скорингом по f' из имени),
теряя точные ND/SD диафрагмы, поле, λ и RI-матрицу OPJ. Сам парсер
к тому же падал голым struct.error на зеркальных маркерах gidx:
`n_glass = max(gidx)` включал 0xFFFE/0xFFFF (YBBS77_, GTIN05).

**Фикс**: `fileio/standalone_opj.py` —

- `parse_standalone_opj(data)` — строгая раскладка с проверками:
  выход за пределы файла / мусорный индекс среды (0xFFFD у ГОЭ) →
  чистая `StandaloneOpjError` вместо struct.error; маркеры
  0xFFFE/0xFFFF не потребляют RI-строки; сан-лимиты |C|≤100 1/мм,
  |d|≤1e4 мм, RI 0.5..5.0 (ИК: Ge n≈4.00324 при λ=10 мкм —
  US00KI02), λ 0.1..30 мкм;
- `standalone_to_system` — прежняя семантика харнесса (n_override из
  RI-матрицы, маркер 1e20 → терминальная толщина 0, без
  виньетирования) + зеркальные маркеры → `is_reflective`;
- `load_standalone_opj(path)` — вход загрузчика.

Харнесс алиасит портовый вход (`opj_to_system is
standalone_to_system`, обёртка `parse_golden_opj` читает файл);
`catalog/library` пробует строгий разбор первым — успех = prescription
достоверен, скоринг эвристик не нужен; `StandaloneOpjError` →
эвристики как прежде (lbo-путь не тронут).

**Размах**: стенд 85 файлов (83 .OPJ + 2 .opj) — 84 strict-OK,
единственный отказ GTIE00 (ГОЭ, досье §6) чистой ошибкой — run_all
по-прежнему даёт заметку ОШИБКА; архив extracted — 82/83. Вердикты
харнесса не изменились (G103/Y5/R4/S48): на банке разбор бит-в-бит
эквивалентен прежнему.

# §P6 — ближний предмет (obj=1): реверс OPJ + верификация 7 систем

## P6.1 — предмет в standalone-OPJ: f64@0x4C

Положение предмета — **f64 по смещению 0x4C** (мм от первой
поверхности): <0 — действительный предмет слева, >0 — мнимый справа.
Валидация Sp (дптр) всех 7 систем: 1000/(sP − z_obj) сходится с
габаритом до 1e-5 (ST4 −96.2046 → 9.717; S_KOND1 −30 ровно → 33.333;
OPTICS#1 +85.1495 мнимый → −19.576). Порт `fileio/standalone_opj.py`
читает поле как `object_pos`; 0x6C под предмет не подходит (значения
2.0/−10.0/−6.667/0.0 — это SD диафрагмы, GFIX P1).

## P6.2 — конвенции ближнего предмета

Веер: из точки предмета под углом u = arcsin(zone·Ax), Ax = sin NA
габаритной строки N=0. Мнимый предмет: старт слева z0 = −(|z|+100),
прицел в точку предмета. Н ЗР = 100·tg(u) — все 7 систем GREEN.
Полудиаметры 0 → UNLIMITED_SD (OPJ их не хранит, ST4 нужен 12.6 мм).

Дальнее изображение (img=0): прод (дптр) = 1000/L − 1000/L_p,
попер (гр.мнсек) = −(slope − u_p)·206265 в печати DD.MMSS,
Tg'*100 = высота луча в плоскости выходного зрачка (знак эталона).
Ближнее (img=1): прод/попер в мм — L − L_ref и y в плоскости
z_last + L_ref, Tg'*100 = −100·tg u'. Афокальный выход (|u_p| ≤ 1e-6,
ST4/LAB6_GAS — предмет в переднем фокусе): прод = 1000/L,
волновые — плоскость выходного зрачка.

**Мнимое изображение (L_p < 0, OPTICS#1)**: опорная плоскость строк —
вершина последней поверхности, не точка Гаусса: прод = L (строка
зона-0 −17.742 = |L_p|), попер = −y на вершине, Sp2 = 1000/sP′
(−16.401). Остаток 0.18 %·зона² (как у S_KOND1 0.26 %) — систематика
порта. Волновые мнимого изображения: со старта веера на плоскости
вычитается сагиттный эксцесс фазы R0−√(R0²+y0²) (≈2 мм = 4·10³ λ);
остаток −6.6λ против −316 эталона — опора OPAL не найдена (OPEN).
