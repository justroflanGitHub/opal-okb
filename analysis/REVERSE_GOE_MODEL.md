# Модель ГОЭ OPAL — реверс обработки 0xFFFD (TASK_GOE)

**Статус:** OPEN — параксиальная модель имплементирована (эффективная
кривизна κ(λ)·C), физика записи восстановлена до архитектуры каскада;
замкнутая формула из OPALA_unp не выведена. Спор Sp′ GTIE00 закрыт
заглушкой→моделью.

Источники: `C:\GOLDEN_DOS\OPALA_unp.EXE` (распакованный кодовый),
`reverse_data/golden/bank/GTIE00.PRN` (эталон), раскладка OPJ —
досье REVERSE_GTIE.md. DOSBox не запускался — только статический
разбор (дизасм x87 + численные фиты).

## 1. Что establecido (главное)

1. **ГОЭ — трансмиссионный дифракционный элемент, НЕ зеркало.**
   Численная геометрия зеркального сэндвича GTIE00: маргинальный луч
   после S2 приходит на ГОЭ S3 в (y=11.54, z=14.91); чтобы замкнуть
   путь на следующую поверхность, луч должен ПРОЙТИ S3 (прямое
   прохождение) или отклониться на ±0.1342 = rec[0]·λ0/λ — зеркало
   (спекулярное отражение) отправляет луч мимо S4 (MISS при любом κ).
   Заглушка порта (is_reflective) геометрически неверна; верна только
   параксиально (см. §3).
2. **Replay-скейлинг λ0/λ на сины лучей записи.** Бинарник 0x9d7a:
   `[3bd0]=[3b78]/t; [3bd8]=[3b80]/t+…`, t = λ/λ0 (аргумент qword
   [bp+0x12]). Единичность вектора записи возможна только при
   λ0/λ-нормировке (λ/λ0 дало бы |s| = 6.05 > 1). Это классический
   hologram replay: дифракционная добавка ∝ λ0/λ.
3. **Каскад ротаций (марш).** После построения локальных осей ГОЭ
   (полуугловая ротация Родригеса: [3be0] = k|s|²/(√(1−…)+1) и т.д.)
   бинарник крутит векторы записи по поверхностям каскадом
   s′ = −(d + [3b28]·s)·[3bf8], d′ = [3bf8]·s (0x96e2/0x9783) по
   массивам шага 0x18: позиции 0x3c58+0x18k, направления 0x3d18+0x18k.
   Коэффициенты [3b28]/[3bf8] считаются в 0x12ad3 через atan-класс.
4. **Диспетчер дифракционного семейства:** 32-битный код типа в
   [−10,−1] (cmp [bx+2],−1 / cmp [bx],−0xA) — ветвление по видам
   ГОЭ/решёток; ветки записи 0x9f2b / 0xa13b строят пары
   (A,B)-коэффициентов нормировки координат q=(A·X+B·Y)/r.
5. **Фальсификация κ-модели для реальных лучей:** κ-зеркало
   совпадает с банком параксиально (вергенции 0.2 %, bfd-хроматизм
   точно), но маргинальный луч MISS S4 ⇒ κ-зеркало — только
   параксиальная эффективизация, не физика.
6. **Полудиаметры не сохранены в OPJ** (нулевая таблица, REVERSE_GTIE
   §4) ⇒ порт не может воспроизвести геометрическое замыкание
   (обход малой S4 комбинаторным отклонением ГОЭ) — реальные веера
   GTIE00 недостижимы для трейсера порта в принципе; это задокументи-
   рованный блокер, не дефект модели.

## 2. rec-таблица записи GTIE00

`rec = [0.9015, 1.0, 0.000485, 1.0, 0.6328, 0.0, 0.0, 100.0]`

| слот | значение | прочтение |
|---|---|---|
| rec[0] | 0.9015 | sin θ луча записи A (θ≈64.3°, внеосевой носитель) — **пин**: δ-отклонение маргинального луча 0.1342 = rec[0]·λ0/λ замыкает геометрию |
| rec[4] | 0.6328 | λ0 записи, HeNe 632.8 нм — **подтверждено** (REVERSE_GTIE §4) |
| rec[2] | 0.000485 | кандидат: кривизна волны записи A, 1/мм |
| rec[7] | 100.0 | кандидат: плечо точечного источника записи B, мм |
| rec[1]/rec[3] | 1.0 | флаги/порядки |

Физическая модель-кандидат (меридиональная): ГОЭ = призма+линза,
s_out = s_in + m·(λ0/λ)·(s_A(y) − s_B(y)), A плоская волна sin 0.9015
(возможна кривизна rec[2]), B точечный источник. Чистая двухволновая
оценка chirp φ = (λ0/λ)(c_A − 1/100) ≈ 0.0015 1/мм недодаёт
требуемой эффективной силы 0.0105 1/мм ×7 — не сведено (кандидаты:
анаморфотные cos-факторы внеосевой решётки при 64°-записи, вклад
подложки, точная формула каскада §1.3). Открыто.

## 3. Параксиальная модель (имплементирована)

Эффективная кривизна ГОЭ C_eff(λ) = κ(λ)·C:

```
κ(λ) = 1.089185 + 5.27e-4·(λ − 4.25)      # GOE_KAPPA_LAW
```

- пины: точное решение по вергенциям GTIE00 при λ = 4.25 (Sp′ дптр
  −29.772/−29.833/−29.691 на λ 4.25/3.5/5.0), наклон — bfd-хроматизм
  банка (diff −0.01054/+0.01418); закон линейный по λ, альтернативы
  λ²/λ0/λ ложатся в тот же шум фита (resid ≤ 1.5e-5 — неразличимы
  на 3 точках);
- остатки модели: вергенции ≤ 0.073 дптр (0.24 %), bfd(λ)−bfd(4.25)
  −0.0161/+0.0087 мм против банка −0.0105/+0.0142;
- закон феноменологический (пин один файл GTIE00), физическая
  мотивация — λ-дисперсия эффективной силы решётки: требуемая
  dκ/dλ > 0 компенсирует дисперсию ИК-окна CaF₂ (n: 1.414→1.399 на
  3.5→5.0), направление согласовано с replay-механикой λ0/λ.

Имплементация:

- `domain.calculations.GOE_KAPPA_LAW` + `goe_effective_radius()` —
  закон и R_eff = R/κ(λ); применяется в двух параксиальных лучах
  `paraxial_trace` (зеркальная ветка φ = −2n/R_eff — на ней пинят
  вергенции);
- `fileio.standalone_opj`: ГОЭ-поверхность = `SurfaceType.HOLOGRAM`,
  `is_reflective=True` (параксиальная семантика зеркала; физика
  элемента трансмиссионная — §1.1), `hologram_wavelength` = λ0 HeNe,
  `hologram_coeffs` = rec f32×8, `hologram_kappa` = (κ, dκ/dλ,
  λ привязки = основная λ системы);
- реальный трейсёр оставлен на зеркальной семантике: смена на
  прохождение давала бы мусорные веера вместо SKIP (полудиаметры
  не сохранены, §1.6).

Верификация: GTIE00 Sp GREEN → GREEN, Sp′ RED(~25 %) → GREEN
(Δотн 6.7e-05), счёт G:7 Y:1 R:0 S:24; полный pytest 1154/8.
