## Сверка с Python-портом (analysis/aberrations.py)

Понятийное соответствие подтверждено:
- Z'm / Z's (астигмат. отрезки) → `compute_field_aberrations` → `z_m`, `z_s`, `astigmatism`
- Tg'*100 (наклон главного луча) → `compute_chief_ray_characteristics`
- Неизопл. → `compute_isoplanatism` (+`DEFAULT_ISOPLANATISM_EPS_DEG=0.5`)
- Дисторсия Del% → `distortion` в `compute_field_aberrations`
- TABGL (сводка главных лучей по зонам поля: предмет/изображ./дисторсия/Z'm/Z's/C'm/C's) → `compute_field_aberrations` (analysis/aberrations.py:551) + каустики §8; угловая мера «гр.мнсек» в порте не выводится
- TABESB (световые высоты габаритных лучей по поверхностям) → `GAUGE_RAYS`/`compute_gauge_rays` (analysis/aberrations.py:1559/1568) + `_build_gauge_rays_tables` (gui/analysis_panel.py:1602)
- TABPR2 (хроматизм увеличения/положения по полю) → `compute_chromatism_opal` (analysis/chromatism.py:187) — частично (сводки по зонам нет)
- Подгонка изображения OPAL → `fit_focal_length`/`fit_bfd`/`fit_magnification` (optimizer.py:455/557/683)
- AVTO (.REG-проигрыватель), TABBEA (таблица виньетирования/светораспределения), TABEAP (экранные зоны), опции «острого края»/экранирования — аналогов в порте НЕТ
- Каустики (радиусы, Z'm/Z's в %) → `_find_focal_z` (фокусные кривые)
- Волновые аберрации → `trace_wavefront_hexapolar`, `_ray_wavefront`
- Меридиональное/сагиттальное сечения → `trace_aberration_fan`, `compute_oblique_fan`

Формат TABRAY `(1X,i3,4(f9.3,a1),f8.3,f8.3,a1,f9.3,f8.3)` — 8 колонок чисел с a1-разделителями: сверить порядок колонок fan-таблиц порта при экспорте 1:1 (если понадобится DOS-совместимый вывод).
