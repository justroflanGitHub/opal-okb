# REVERSE_NZR: §19 — «Н ЗР» TABOC2 и словарь терминов DOC-корпуса

*Волна 6 (TASK_REVNZR). Отдельный файл к REVERSE_TRACE.md — сам TRACE не
меняется; §11.3 TRAIL «[НЕИЗВЕСТНО: расшифровка Н ЗР]» закрывается здесь.*

## 19.1. Вердикт: «Н ЗР (мм)» = «H ЗР (мм)» — зрачковая координата луча H в мм

**«Н ЗР» — это «H ЗР» = «(высота) зрачковая координата луча» в миллиметрах.**
Кириллическая «Н» (байт 0x8D) в шапке TABOC2 — омоглиф латинской «H»
(байт 0x48) из пула юнитов того же OPALA.EXE; «ЗР» = «зрачковая». В TABOC2
(осевой пучок) это **входная** зрачковая координата луча в мм:
`Н ЗР = Отн.зр × Ax` (зона зрачка × радиус входного зрачка в мм).

Три независимые линии доказательства:

### 19.1.1. Байтовая: пул юнитов содержит полное имя

Шапка TABOC2 (file 0x408CC–0x40960, §11.3) — «…│ Неизопл. │ Н ЗР │ Z'm │
C's», строка юнитов «(дл. волн) │ (%) │ (мм) │ (мм) │ (мм)». Буква в
«Н ЗР» на file 0x40901 — **0x8D (кириллическая Н)**.

Пул юнитов экранных форм, file 0x44500–0x445B8 (новая находка волны 6):

```
(гр.мнсек)    (дптр)      (мм)      (дптр**2)  (дл. волн)     (%)
  (tg*100)   (tg'*100)  (H' ЗР(мм))  (H ЗР(мм))   (лин/мм)   (лин/мин)     (sin)
nokгavezад   минсекгрдрад
```

Буквы в «(H' ЗР(мм))» (0x4456B) и «(H ЗР(мм))» (0x44578) — **0x48
(латинская H)** с/без штриха. Штрибх — классическое различение
пространств: **H** (без штриха) — пространство предметов (входной зрачок),
**H'** — пространство изображений (выходная сфера); угловые двойники —
**tg\*100** / **tg'\*100**. Итого четвёрка юнитов — это одна и та же
величина «зрачковая координата луча» в четырёх вариантах, выбираемых по
типу предмета/изображения (ближний/дальний, см. §19.2.2). «Н ЗР» шапки —
пятый (экранный) способ набора той же «H ЗР» кириллической клавиатурой.

### 19.1.2. Числовая: эталон RT__2236.PRN — Н ЗР = зона × 5.0000 точно

extracted/opal_okb/**RT__2236.PRN** (система «IR -.2X D=10 2W=72 10L 2USP»
= запись 1 Lib/USBINOCL.LBO, US00KI02.OPJ) — реальный вывод TABOC2:

```
 ─       │     Волновые аберрации      │ Неизопл. │  Н ЗР
 ─Tg'*100│         (дл. волн)          │   (%)    │  (мм)
 ──────────── 0 ─────── 1 ─────── 2 ───┴──────────┴────────
 -20.684     .7532                         -.3546    5.0000
 -17.880     .3620                         -.1628    4.3301
 -14.582     .1354                         -.0465    3.5355
 -10.306     .0279                          .0050    2.5000
    .000     .0000                          .0000     .0000
```

Первая таблица того же PRN печатает зоны «Отн.зр koop.» 1.000/.866/.707/.500
(зоны зрачка равной площади, n=4 — та же схема √(k/n), что зоны поля
TABGL). Сверка Н ЗР с зона×радиус-зрачка (D=10 → 5 мм):

| зона | зона×5 (точно) | печать Н ЗР | Tg'\*100 | Tg'\*100/край (доля зоны) |
|---|---|---|---|---|
| 1.000 | 5.000000 | **5.0000** | −20.684 | 1.00000 |
| .866 | 4.330127 | **4.3301** | −17.880 | 0.86445 (−0.18%) |
| .707 | 3.535534 | **3.5355** | −14.582 | 0.70500 (−0.28%) |
| .500 | 2.500000 | **2.5000** | −10.306 | 0.49826 (−0.35%) |
| .000 | 0 | **.0000** | .000 | — |

Н ЗР линеен по зоне **точно до 4-го знака** (4.330127→«4.3301»,
3.535534→«3.5355» — округление печати), а трассируемая выходная величина
Tg'\*100 отклоняется от пропорциональности на −0.18…−0.35% (сферическая
аберрация наклонов, ср. волновую .7532 дл. волн на краю). Значит Н ЗР —
**номинальная входная координата** (зона × Ax), а не результат трассировки
(выходная высота несла бы ту же аберрационную нелинейность, что Tg'\*100).

### 19.1.3. Документальная: ANALIZE.DOC п.4.6 «Аберрации неглавных лучей»

* ANALIZE.DOC:669–673: «**Входные координаты лучей** распределяются
  равномерно по квадрату **зрачковой координаты** соответствующего сечения
  **входного зрачка** данного пучка» — входная величина = зрачковая
  координата (нормированная; в мм = зона×Ax).
* ANALIZE.DOC:674–680: «**Выходные зрачковые координаты** лучей выводятся
  для изображения ближнего типа как умноженные на 100 тангенсы углов…
  Для изображения дальнего типа выводятся в мм координаты точки
  пересечения луча с **выходной сферой**…» (тот же текст — SPACE.DOC:365–376,
  строка «ВЫХОДНЫЕ ЗРАЧКОВЫЕ КООРДИНАТЫ»).
* Так пара колонок TABOC2 получает полный смысл: метка строки **Tg'\*100**
  (или Y — вариант в данных формы 0x40920 «─Tg'\*100│Y») = выходная
  зрачковая координата, замыкающая колонка **Н ЗР (мм)** = входная.

## 19.2. Сопутствующие находки

### 19.2.1. Формат и вариантные наборы колонок TABOC2 (уточнение §11.3)

Формат `(F7.3,3F10.4)`: F7.3 = метка строки (Tg'\*100/Y — выходная
зрачковая координата), 3×F10.4 — величины по селектору `[0x34b8]` (§11.2).
Эталон RT__2236 (осевой пучок) печатает **Волновые, Неизопл., Н ЗР** —
ровно 3 из 5 величин шапки; Z'm/C's — вариант внеосевого пучка (для
осевого они вырождены, ср. осевую строку N=0 TABGL — вся нулевая).
Шапка с пятью именами — «супернабор» для всех вариантов таблицы.

### 19.2.2. Единицы «ближний/дальний тип» (правила из DOC)

Тип предмета/изображения задаётся в «Формировании» (OPAL.DOC §3.4.1.1–2:
ближний = «на конечном расстоянии», дальний = «на бесконечности»).
Правила печати (ANALIZE.DOC:659–680, 1137–1138, 1283–1284):

| Величина | ближний тип | дальний тип |
|---|---|---|
| поперечные аберрации | мм | гр.мнсек (угловое отклонение) |
| продольные аберрации | мм | дптр |
| Z'm/Z's | мм | дптр (от выходного зрачка) |
| выходные зрачковые координаты | tg'\*100 | мм на выходной сфере (H' ЗР) |
| сдвиг плоскости (DS'), ЧКХ-частоты | мм, лин/мм | дптр, лин/мин |
| величина предмета/изображения | мм | гр.мнсек (½ углового поля) |
| Sp/Sp' | дптр от предмета/изображения | мм от первой/последней поверхности |

Этим и объясняется RT__2236: продольные «(дптр)» + поперечные
«(гр.мнсек)» — изображение дальнего типа, поэтому выходная зрачковая
координата луча там и есть угловая Tg'\*100 (а не H' мм).

### 19.2.3. Меры углов

* «(гр.мнсек)» — составная печатная мера: **градусы + минуты/100**
  (9.09104° → «9.054624»; дешифровка и эмуляция — analysis/tables.py:124
  `_grminsec`, волна 5).
* Пул 0x445A8–0x445B8: «минсекгрдрад» — переключатель мер угла
  (минуты/секунды/градусы/радианы), «нокгavezад» — строка-селектор мер
  (наборы латиницей, вероятно н/о/к/г/а/в/е/z/а/д = варианты МЕРЫ
  ПРЕДМЕТА/ИЗОБРАЖЕНИЯ из п.4.5: tg/углы/синусы — точная раскладка
  [НЕИЗВЕСТНО: рантайм-строка]).
