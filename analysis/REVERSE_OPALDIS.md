## 2. OD1 — принципиальная сфера волновых — ЗАКРЫТА (правило + банк)

### 2.1. Правило (из дизасма)

Опорная поверхность OPAL — НЕ глобальная сфера. Замыкание волнового
OPL — **марш по поверхностям с квадратичной формой** (общий хвост
0xd074-0xd0c2, выполняется на каждой поверхности):

```
W₂ += [X²·[3D60] + 2XY·[3D78] + Y²·[3D80]] · A/2
```

- X,Y — координаты луча на текущей поверхности ([0x3A10]=−X, [0x3A14]=−Y);
- тензор [3D60/3D78/3D80] — дифференциальный след Коддингтона: посев
  лаунчером 0xa1db-0xa2f4 (тензор = (коорд+[0x3AD0])·косинус отrecords
  1/2), прогон через поверхности, **инверсия якобиана** в хвосте cd62
  ([0x4D9E] = det 2×2 записей 3/4; T ← A_rec·T/det);
- A = qword[0x3A80] = **mixed** = [0x3C98]/([0x3D30]·[0x3D38]²) — выход
  93f3 @0x97db (cond [0x39EC]==2 && [0x39EE]==0): кривизна смешанной
  каустики, произведение ТРЁХ наклонов в знаменателе (комбинация
  3-го порядка — отсюда не-гауссов центр у мнимого изображения);
- флаг мнимого изображения [0x4DCA] = −1.0 ставится в хвосте 0xcd89
  (arg7≠0 && arg·[3BE8]>0 || arg·[3BF0]>0 — положительные направляющие
  косинусы = выход пучка назад).

Эффективно на выходе (последняя поверхность, координаты y_last):

```
W(зона) = ΔOPL(→z_last) + κ·(y²зон − y²глав)/2,   κ = A·(тензор) ≈ 1/(C − z_last)
```

— сагитта квадратичной формы на плоскости последней поверхности.

### 2.3. Формулировка для порта

- L_p>0 (реальное): центр опоры = точка Гаусса, сагитта = точная сфера
  (квадратика эквивалентна до 1e-9 при больших R). Порт уже так делает;
  чинить точность `_ray_wavefront` отдельной волной.
- L_p<0 (мнимое): сагитта = κ·y²/2 на z_last с κ из mixed-каустики
  Коддингтона (пер-λ!); гауссова опора порта даёт сотни λ ошибки
  (C=62.61 против 70.8: остатки [309,232,155,78]λ). OPTICS#1 в сверке
  SKIP (obj=1) — правило задокументировано для будущей волны.

Знак: W = OPL(зона) − OPL(главный) с отриц. сагиттой при мнимом
изображении (банк печатает −316λ у зоны 1.0).

Декодировано (dis_main.txt, полные диапазоны):

- **0x94cc-0x9531**: координаты луча [3BD0]/[3BD8] и память [3BE8]/[3BF0]

## 3. OD2 — кромочный Tg-знак — ЗАКРЫТА (правило двухпроходного веера)

### 3.1. Механизм (дизасм)

- Сетка веера a776: при [0x39E2]<0 (или ==0 с [0x39E0]==0) счётчик зон
  = **−([0x39D8:39DA]+4)** — отрицательная (зеркальная) сетка; иначе
  +([39D8]+4) — прямая. Драйверы таблиц (b5e9/b8e4/b940/b9b7/b9fc/8d5b)
  инициализируют `[0x39E0:39E2] = −4−[0x39D8:39DA]` (зеркальный проход
  первым), цикл марша 0xff9:22dc/{f359} восстанавливает счётчик из
  [0x526A/0x526C] на каждом шаге.
- В хвосте марша cd62: `[0x39E2] < 0 → jmp 0xd6d4` — **зеркальная ветка**
  (знаковая инверсия геометрии); флаг мнимого изображения [0x4DCA]=−1.

⇒ Веер = ДВА прохода: зеркальный прогон заполняет строки таблиц;
прямой прогон ПЕРЕЗАПИСЫВАЕТ строку, только если прямой луч дошёл
без особой ситуации. Выживший зеркальный луч: |прод|, |попер|, |W|
совпадают с прямым (симметрия), **метка Tg′*100 — с обратным знаком**.

## 4. OD3 — печать поперечных гр.мнсек (DD.MMSS) — ЗАКРЫТА (правило + банк)

### 4.1. Правило

Гр.мнсек-печать появляется ⇔ **img=0 (дальнее изображение)** — 6 систем
банка: US00KI02/KURSOVIK (obj=0), LAB6_GAS/OBEKTIV/OKULAR/ST4 (obj=1).

**Величина**: угол, под которым из ЦЕНТРА ВЫХОДНОГО ЗРАЧКА видна точка
пересечения зонального луча с параксиальной плоскостью изображения:

```
α = −y_зон(гаусс)/(L_паракс − sP′) · 206264.8″/рад,
y_зон(гаусс) = y_exit + slope·L_паракс
```

(«−» = инверсия знака порта). Афокальный выход (L_паракс→∞: ST4/LAB6_GAS —
предмет в переднем фокусе) вырождается в наклон луча: α → −slope·K.

**Формат DD.MMSSss**: DD + MM/100 + SS.ss/10000 — минуты двумя разрядами,
секунды с ДВУМЯ десятичными (US00KI02 .062432 = 0°06′24.32″; OBEKTIV
1.130483 = 1°13′04.83″); KURSOVIK печатает секунды без десятых
(−3.203 = −3°20′30″). Знак вынесен наружу. Хелперы `ddmmss_value` /
`arcsec_of_ddmmss` (golden_verify) — с клампом переноса разряда
(печать OPAL его не делает).

## 5. OD4 — per-λ Ax (E3) — ПРАВИЛО НАЙДЕНО (валидация остатками)

### 5.1. Правило

λ-колонки таблиц строятся **повторной трассировкой с пер-λ показателями**
(wl_flags, [0x50c2]=1, f359+e920 — TRACE §9.2), и кромка веера тоже
пересчитывается: **Ax(λ) = габаритная N=0-строка блока «Длина волны λ»**
(крайний аксиальный луч при показателях λ), НЕ фиксированная Ax(λ0).

OPTICS#1 (λ0=.5461, NA=0.125): габаритные N=0 строки дают
**Ax = .12500 (.5461) / .12587 (.4340) / .12455 (.6563)** — апертура
варьирует на ±0.5 % по хроматизму ТК16/Ф4.

### 5.2. Доказательство (коллапс остатков)

Харнесный веер `near_object_axial_fan` с ФИКСИРОВАННОЙ NA=0.125:
остатки трёх λ распадаются на три параллельные ветви (хроматический
разброс Ax маскируется). С **per-λ NA = Ax(λ)** остатки всех трёх λ
коллапсируют в один общий паттерн: ΔL ≈ −0.0325·z² мм, Δy ≈ +0.005·z³
(0.2 %) — единый для λ-семейства, т.е. объяснимый оставшейся разницей
запуска (выходные наклоны при этом совпадают с банком до 4–5 знаков:
14.9236/12.9074/10.5240/7.4331 vs 14.923/12.908/10.526/−7.433).

### 5.3. Для порта

Веер λ-колонки: NA := Ax(λ) из габаритной таблицы (или пересчёт
габаритного луча при n(λ) — эквивалентно). Остаточный общий паттерн
ΔL≈−0.0325·z² — открытый подпункт (запуск OPAL отличается на 0.2 %,
кандидат — прицел в плоскости зрачка/предмета).
