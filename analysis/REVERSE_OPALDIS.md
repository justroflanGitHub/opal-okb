## 0. Адресные конвенции и инструменты

- Досье §EDGE/REVERSE_0746 используют СТАРЫЕ линейные адреса (load 0x10000):
  **новые = старые − 0x10000** (Э19 W₂: старый 0x11240 → новый 0x1240).
- Сегменты: CODE_MAIN 0x0000-0xFF90, CODE_MATH 0x0FF9, RTL 0x1F78/0x2E73,
  OVERLAY 0x3F60 (в образе нулевой — принтеры TABOC там, статически недоступны),
  DATA_4617/506E/52A6/52D4, DGROUP 0x552F (DS-глобаль g → file 0x552F0+g).
- Дизассемблер: `py analysis/_tools/_dis_opaldis.py <lin1> <lin2> [...]`
  (x87-эмуляция INT 34..3D из x87dis.py). Декомпил Ghidra:
  `C:\tools\rea-out\decomp_opala_unp\` (789 .c; _funcs.txt `seg:off|name|size|…`);
  старый plain-дамп `C:\tools\rea-out\decomp_opala\` (адреса +0x10000).
- FORTRAN: ближние call — аргументы left-to-right, первый на [bp+6]; «общие хвосты»
  (гэпы между функциями Ghidra) = продолжения рутин с несколькими entry points.

## 1. OD-карта вызовов (волновой тракт)

Реконструированная цепочка накопления W₂ (волновая аберрация, OPL-аккумулятор):

| Адрес (новый) | Роль |
|---|---|
| 0x93f3 (8490-б sibling 3b99?) — prologue | λ→n дисперсия (lcall 0ff9:0019); W₂ += [0x3C20]·n(λ); [0x3C20]=длина сегмента d; цикл [0x3C30+8i] = (x+c)·prev·q + x·W₂; [0x3A10]=−X, [0x3A14]=−Y (fchs) |
| Э19 0x120c-0x1330 (0746) | a21≥5: W₂ = W₂ − [0x3B50]; a24>1: W₂ −= qword[0x3B48+8·[0x4506]]; слоты a3+0x10 ← W₂ |
| 0xb8e4 (FUN_b8e4, 88 б) | **[0x3B50] ← W₂** (movsw×4 из 0x3c28) — сейв опорного OPL главного луча; [0x4cbc]=[0x39d8]+1, [0x4c7e]=2 |
| гэп b472-b8e4, блок 0xb5aa-0xb5e6 | [0x3B48+8·[0x4c88]] = T·[3bf0] − W₂ − [3b50] — per-iteration референс |
| **0xd074-0xd0c2 (общий хвост)** | **W₂ += [X²·[3D60] + 2XY·[3D78] + Y²·[3D80]] · A/2**, A = qword[[bp+0x16]], [2e2a]=2.0 — замыкание на опорную квадру (астигматический тензор от e7db-Коддингтона) |
| 0xd849 | W₂ += arg/2 · Y² · [0x4dae] — меридиональный вариант замыкания |
| 0xfd96 (jmp с 0xfe26, f359-регион) | if [0x50c2]≠1: W₂ += [0x3C20]·arg[bp+0x16] — финальный сегмент d·n |
| call-site 0x1037-0x105c | пуш-порядок ⇒ arg[bp+0x16] = &0x3A80 → **A = qword[0x3A80]** — кривизна опорной сферы |

Замыкание = сагитта квадратичной формы на опорной поверхности с кривизной A:
`W₂ += QF(X,Y)·A/2` — классическая «reference sphere» в параксиальном приближении
(сагитта z²/2R). Итог: W_final = W₂ − [0x3B50](OPL глав. луча) − [0x3B48+8i](per-iter).

**Писатели [0x3A80]** (кандидаты правила OD1): 0xb8dd (гэп b5e9-b8e4),
0xbd9b/0xbdeb (FUN_babf), 0xc6c7 (FUN_c6bc, 113 б), 0xcc98 (FUN_ccb8, 162 б).
Читатели: 0746 (аргумент 93f3/9897), гэп b4d0-регион.

FP-константы DGROUP: [2e0e]=1.0, [2e16]=0.0, [2e1e]=−1.0, [2e2a]=2.0, [2e96]=1.0,
[2ea0]=2.0, [2eb0]=−1.0. Глобали 0x3xxx/0x4xxx в статике нулевые.

## 2. OD1 — принципиальная сфера волновых (OPTICS#1, мнимое изображение)

Открыто. Известно из §EDGE E6 (REVERSE_GFIX): остаток эталона = −0.1691·z² мм,
дефокус опоры δ=−15.18 мм, точность 0.2 %; долина 2D-ската вырождена. Порт:
центр=Гаусс 62.609 / вершина=zp 19.379 / R=43.23. Ожидание: центр в точке Гаусса,
радиус/вершина от особой плоскости.

План: дизасм писателей [0x3A80] → какая кривизна кладётся при ближнем/мнимом
изображении → сверка A с δ=−15.18 мм (A ≈ 2δ·tg²u′/… по QF-замыканию) → харнесс.

## 3. OD2 — кромочный Tg-знак (121 з.1.0: +20.845 эталон vs −20.824 порт)

Открыто. Кандидаты: запуск зоны 1.0 (a776 сетка веера + 9d7a запуск луча —
стартовые координаты 0x3A90→0x3BD8, 0x3A98→0x3BE0, косинусы [0x3B78]/v, [0x3B80]/v
+ [0x3AA0]); [0x3A10]=−X/−Y в 93f3 — возможный источник знаковой конвенции.
TRACE §7.4: разностные выходы `(−M) − D[0x3D90+0x18k]` — семейство Tg' (TABGL).

## 4. OD3 — печать поперечных гр.мнсек (DD.MMSS)

Открыто. Форматы: *TABOC2(F7.3,3F10.4) @5359:0005 (волновые/неизопл/Н ЗР),
*TABOC1(f6.3,f12.5,2f11.5) @534a:0005 (прод/попер) в DATA_52D4. Прямых ссылок из
CODE_MAIN на сегменты форматов нет — диспетчеризация через DGROUP-таблицу
«TABESB TABRAY / TABPR2 TABGL TABEAP 22 TABBEA / TABOC2 TABOC1 / TABAX3 TABSAG»;
тела принтеров — в оверлее (статически нулевом). Конвенция DD.MMSS —
округление/знак форматирующей стороны.

## 5. OD4 — per-λ Ax (E3)

Открыто. TRACE §9.2: хроматизм = повторная трассировка с другим n (wl_flags,
[0x50c2]=1, f359+e920). Кривизна Ax при λ≠λ0 — см. писателей [0x3A80] (OD1).
