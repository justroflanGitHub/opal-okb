## 1. OPALOPT.DOC — методы и язык оптимизации (полная сводка)

### 1.1. Работы

| работа | критерий качества | модуль (сверка) |
|---|---|---|
| **OPT** — «Оптимизация геометрических аберраций» | поперечные/продольные аберрации отдельных лучей по точкам поля | `OPALO.EXE` — справка OPT.OH «Описание марок для оптимизации геометрических аберраций» ([REVERSE_OPALO](REVERSE_OPALO.md) §1); словарь `OPT.TRA`; шаблон `FORM.OPT`; данные `*.OPT` |
| **OPTW** — «Оптимизация волновых фронтов» | коэффициенты зонального полихроматического разложения волновой аберрации по ортогональным полиномам от зрачковых и спектральных координат (= Цернике) | `OPALOW.EXE` — справка OPW.OH «…коэффициентов Цернике»; шаблон `FORM.OPW` (`MF(*)=CWZ;`); данные `*.OPW` |
| **OPTZ** — «Оптимизация центрированных ОС с переменными характеристиками» | правила = OPT + состояния (§1.9) | EXE-носитель в DOC не назван; [НЕИЗВЕСТНО] (кандидаты по данным `*.VP` — см. §3.4) |

Документ ~1995-03-21; версия языка та же, что читает OPT.TRA (§1.8).

### 1.2. Постановка задачи (OPALOPT:35–38)

Поиск комбинации параметров с наилучшим качеством при заданных ограничениях.
Три обязательных элемента задания: **критерий качества** (MF) + **список
варьируемых параметров** (PAR) [+ **ограничения**]. Минимум данных для запуска
— операторы MF и PAR (OPALOPT:209–212).

### 1.3. Мерит-функция (критерий качества)

Формула оптимизируемой функции (OPALOPT:701–713):

```
оф(I) = (офт(I) − офз(I)) / офн(I) × офв(I)
        текущее   заданное    норма       вес
КРИТЕРИЙ КАЧЕСТВА = Σ оф(I)²   (сумма квадратов)
```

- умолчания: заданное 0, вес 1, норма — по типу характеристики:
  **продольные 0.1 мм / дптр; поперечные 0.01 мм / градуса; коэффициенты
  разложения — в единицах основной длины волны** (OPALOPT:167–172, 732–737);
- вес ↔ норма взаимозаменяемы (уменьшение веса ≡ увеличению нормы,
  OPALOPT:79–81);
- для OPTW коэффициенты CWZ «автоматически нормируются так, что сумма их
  квадратов = средний квадрат аберрационной функции» → машинный критерий
  адекватен СК волновому фронту (OPALOPT:107–112);
- смешанный критерий допустим: аберрации + параксиальные характеристики
  (пример: `MF(1-4)=VG0,L,SG',SP0'` OPALOPT:151–156).

### 1.4. Параметры оптимизации (PAR, PARF/PARC/CC)

Типы (табл.1, OPALOPT:1122–1137): кривизны **C**, толщины **D**, эксцентриситет
**ES**, коэффициенты асферики **CA**, параметры ГОЭ: **CHL/CHR** (кривизны),
**WLH** (длина волны записи), **CH** (коэффициенты высшего порядка), **SO**
(передний отрезок), **SI** (задний отрезок), **SD** (положение диафрагмы).

- лимит: **≤ 64 параметров** (OPALOPT:448, 530);
- марки: индивидуальные `C/3`, групповые `C/1-10`, полная группа `C`;
  знак минус — исключение из набора: `PAR(1-4)=C,D/1-9,-C/5,-D/5-7`
  (пример 2, OPALOPT:293);
- **связи** между параметрами — линейные `пз = кс × пс` (§2.2, OPALOPT:462–549):
  тройка операторов **PARF** (свободные) / **PARC** (связанные) / **CC**
  (коэффициенты), все три обязательны; допустимые пары: радиус–радиус,
  радиус–толщина, толщина–положение диафрагмы, передний–задний отрезок,
  передний отрезок–радиус 1-й поверхности, задний отрезок–радиус последней;
  связанные параметры НЕ указываются в PAR. Пример симметрии (пример 7):
  `PARF(*)=C/1-3,D/1-2; PARC(*)=C/6-4,D/5-4; CC(*)=-1,1;` (обратные
  диапазоны C/6-4 = C/6,C/5,C/4).

### 1.5. Ограничения-равенства (EQF)

Формула (OPALOPT:869–878): `фр(I) = (рвз(I) − рвт(I)) / рвн(I)`, должно
выполняться `−рвд ≤ (рвз − рвт) ≤ +рвд` (допуск).

- операторы: **EQF** (марки, **≤ 20 функций**, OPALOPT:889–892), **EQF#**
  (заданные; умолчание — исходные значения), **EQFS** (нормы);
- умолчание допуска по типу характеристики (например, увеличение ±2 %,
  OPALOPT:248–250);
- **«восстановление»**: если EQF# задаёт значения ≠ исходных, перед
  оптимизацией все они подгоняются специальной процедурой, критерий при этом
  не контролируется (OPALOPT:256–265) — предупреждение документации: лучше
  «сохранять» исходные равенством, а «подгонку» делать неравенствами;
- контролируются параксиальные характеристики и габариты (типично VG0, SG'),
  можно и аберрации/CWZ — «существенно увеличивает время» (OPALOPT:238–244).

### 1.6. Ограничения-неравенства (INF) и штрафные функции

Единственный метод контроля характеристик; для параметров — опция
(§1.7). Формулы (OPALOPT:945–987):

```
нр<(I) = (нрт(I) − нрг<(I)) / нрн<(I)      нижняя граница
нр>(I) = (нрг>(I) − нрт(I)) / нрн>(I)      верхняя граница

ШТРАФ:  шф<(I) = min(0; (нр<(I) − t<(I)) · g<(I))
        шф>(I) = min(0; (нр>(I) − t>(I)) · g>(I))
```

где **t = «сдвиг», g = «вес» — внутренние переменные**, подбираемые
автоматически и постоянные в пределах «цикла» (группы шагов); цель:
`(нрт − нрг<) ≥ −нрд<` и `(нрг> − нрт) ≥ −нрд>` после (не обязательно в ходе)
оптимизации. Операторы:

- **INF** — список марок параметров/характеристик;
- **INF</INF>** — нижние/верхние границы (для параметров необязательны, если
  заданы специализированными C</D>… — прим. 1, OPALOPT:1032–1036);
- **INFT** — допуски на границы; **INFW** — веса (умолчание 1);
- **DE<** — минимальные толщины «по краю» (только нижняя граница);
  **AS>** — максимальные световые высоты (только верхняя).

Балансировка: нормирующие множители по умолчанию по типу характеристики,
**автоматическая перебалансировка** «внутренними» весами/сдвигом в ходе
оптимизации; решение обычно на пересечении «активных» границ
(OPALOPT:402–418). «Слабые» штрафы незаметны на фоне критерия, «сильные» —
уводят от оптимума (там же).

### 1.7. Границы параметров — два метода контроля (OPALOPT:323–358)

Специализированные операторы границ: **C</C>, D</D>, ES</ES>, SO</SO>,
SI</SI>, SD</SD> (+по OPT.TRA ещё N/DNR/NSC/AL/CA/CHL/CHR/WLH/CH, см. §1.8).
Правила: тип границы — по алгебраическому знаку; для толщин контролируется
физическое значение `D·N/|N|` независимо от направления света (OPALOPT:622–632);
SI</SI> учитываются только если SI — параметр (PAR/PARC), иначе контролировать
положение плоскости Гаусса маркой SG' (OPALOPT:649–664).

1. **Метод исключения** (дефолт): параметр, вышедший за границу,
   фиксируется и исключается из варьирования; автоматически возвращается при
   исчерпании ресурсов. Подключается автоматически при наличии границ.
   Требование: в исходной системе ограничения выполнены. Только для
   независимых параметров.
2. **Метод модифицированных штрафных функций**: границы через INF (марки
   параметров в списке неравенств), контроль штрафами §1.6. Универсален:
   работает для связанных параметров и при нарушенных исходных границах.

### 1.8. Управляющие операторы и словарь OPT.TRA (сверка)

### 1.9. Марки характеристик (полный каталог)

Формат марки: `имя/указатели`; `/` опускается без указателей; `*` —
мультипликация (крайне правые `*` опускаемы); `?` — умолчание (OPALOPT:1090–1108).

**Параксиальные/габаритные** (табл.2, OPALOPT:1249–1273; блок = N1*N2, тип
предмета/изображения F/N/?): `V0` — обобщённое увеличение в заданной плоскости;
`VG0` — в плоскости Гаусса; `SG`, `SG'` — положения предмета/плоскости Гаусса;
`DSG'` — смещение плоскости Гаусса; `SP0`, `SP0'` — входной/выходной зрачок;
`L` — сумма толщин; `LS'`/`LS`/`LSS'` — габариты от зрачка/предмета/предмета
до изображения; `OP` — оптическая сила (дптр). Правила отсчёта зрачков/плоскостей
ближний/дальний тип — OPALOPT:1275–1293.

**Конструктивные (только неравенства INF)**: `DE` — толщины по краю (только
нижняя), `AS` — световые высоты (только верхняя), `ID/K` — функция
светораспределения K-го пучка (только нижняя) (OPALOPT:1294–1298).

**Аберрации лучей (OPT)** (табл.3–7, OPALOPT:1313–1519): указатели `LJIS`:
L — хроматизм (0..4, `'` первичный, `"` вторичный, `*` размножение), J — пучок
(0..5), I — луч в половине сечения, S — сечение U/D. Осевой пучок: `DYA`
(поперечные), `DSA` (продольные, I=0..RAYA), `ZA` (аст. отрезки), `DPA`
(неизопланатизм). Главный луч (также `DIS%/DSP/DSP'` в OPTW): `DIS`, `DIS%`,
`DVL`, `DVL%`, `ZM`, `ZS`, `AST`=ZM−ZS, `FCM`=(ZM+ZS)/2, `DSP`, `DSP'`.
Сечения внеосевых пучков: `DYM/LJIS` (меридиональное), `DYS/DXS/LJI`
(сагиттальное), `DYT/DXT/LJIS` (косое). Пример марки: `DYM/221U` =
поперечная аберрация 2-го луча верхней половины меридионального сечения 2-го
пучка для 2-й дополнительной λ (OPALOPT:120–124). Хроматизм L=': NLA=3→L(2)−L(1);
L=": среднее минус L(0) — формулы OPALOPT:1423–1437.

**Коэффициенты разложения (OPTW)**: `CWZ/LJIA` — L=0,1,2 (моно/первичный
хроматизм/вторичный), J — пучок, I — зрачковая координата (2..C, сферическая
аберрация 20→чётные, кома 11,31,…, астигматизм 22,42,…), A — азимут. Полный
набор осевого пучка L=0: `CWZ/0020..00C0` (6 коэффициентов, порядки до 12);
1-й внеосевой: сфера 0120..01C0, кома 0111..01B0, астигматизм 0122..01A2,
прочие 0133..0166 (табл.7–8, OPALOPT:1611–1662). Рекомендация документации:
использовать групповую `CWZ/****` (=CWZ) и корректировать после анализа.

**Мультипликация и корректировка списков** (OPALOPT:1522–1588): групповая марка
разворачивается в набор индивидуальных с пробегом индексов (пример 14:
`DSA/**` при 3λ×2 луча → 8 марок); повторная марка **корректирует** параметры
уже описанных, минус-марка **удаляет** из набора (пример 15). То же правило для
групповых весов/норм/заданных (OPALOPT:853–860).

**Сверка с кодом**: таблица 63 марок OPALOW.EXE (ds:0x6080,
[REVERSE_OPALO](REVERSE_OPALO.md) §1):
`C D ES CA CN N DNR AL SO SD SI CHL CHR WLH CH V0 VG0 SG' DSG' SP0' SG SP0 L
LS' LS LSS' OP DE DEO DEI DED AS ID MTF DSA ZA RCA DPA AST DIS DIS% DVL DVL%
ZM ZS RCM RCS DSP DSP' FCM DYM ZMM ZSM RCMM RCSM DXS DYS ZMS ZSS DXT DYT ZMT
ZST CWZ NARC`.
Совпадения с каталогом §1.9 — ~40 позиций. Дельта кода против доки (не
документированы в OPALOPT.DOC): `CN N DNR AL` (параметры), `DEO DEI DED`
(толщины по краю — есть в OPT.TRA), `RCA RCM RCS RCMM RCSM` (радиусы каустики —
осевая/меридиональная/сагиттальная, ср. C'm/C's §19.3.3), `ZMM ZSM ZMS ZSS ZMT
ZST` (зональные астигматические отрезки лучей сечений), `MTF` (есть в доке
§1.10), `NARC` [НЕИЗВЕСТНО]. Дельта доки против кода: `DYA DYT DXT DXS DYM
V0…` — в OPALOW-наборе нет DYA/DYT/DXT/DXS (у OPALOW свой набор марок, у
OPALO — свой, наборы программ разные, REVERSE_OPALO §1.3).

### 1.10. MTF-марки (спецпоставка, OPTW)

`MTF/IJK` — отступление ЧКХ от безаберрационной: I — пучок, J — частота
(1..4), K — сечение (1 сагиттальное, 2 меридиональное). Операторы: `NFRQ=k`
(1..4), `FRQ(1-k)=…` лин/мм (OPALOPT:1680–1737). Для эффективности требовать
«виртуальный диск»: `SET OPAL_TEMP=G:\` в AUTOEXEC.BAT (OPALOPT:1691–1699) —
свидетельство тяжёлого дифракционного счёта (20 частот — REVERSE_OPALO §8).

### 1.11. OPTZ — переменные состояния (OPALOPT:2072–2289)

Правила = OPT + новое: параметр **DB** — смещения блоков (`DB`, `DB/1-3/5` —
блоки 1–3 в 5-м состоянии); во все марки аберраций добавляется указатель
**номер состояния** (крайний левый: `DSA/***`, `DIS/**`, `DYM/*****`,
`V0/*`); параксиальные получают суффикс состояния (`VG0/n1-n2/FN0`); новое
`DS'0/*` — смещение плоскости изображения относительно 0-состояния.

### 1.12. Сеанс и численный метод — ГЛАВНЫЙ ВЫВОД

Сеанс (OPALOPT:1741–1803): вызов OPT/OPTW из меню или командной строкой →
меню: 1) трансляция данных (редактор, F4 — трансляция, F8 — сохранить, ESC/F10
— выход с автоматической подготовкой: мультипликация марок, расчёт и
аппроксимация аберраций в исходной точке, вычисление штрафов), 2) режимы
оптимизации (краткая сводка — во 2-й информационной строке; настройка), 3)
собственно оптимизация — таблицы хода по **циклам, шагам и основным частям
шага**; F6 — графика: критерий (зелёный) и штраф (красный) по шагам/циклам,
диаграммы вкладов функций в критерий и неравенств в штраф, оптическая схема;
ESC/F10 — завершение.

**Численный метод минимизации в OPALOPT.DOC НЕ описан**: ни метода (Ньютон,
градиент, DLS…), ни формул шага — только структура критерия/штрафов
(«модифицированные штрафные функции», переменные веса/сдвиги, циклы/шаги) и
термины «анализ влияния параметров», «аппроксимация аберраций» — т.е.
документация покрывает постановку задачи и входной язык, а алгоритм — нет.
Следствия: (а) для порта метод следует брать из кода OPALO/OPALOW
([REVERSE_OPALO](REVERSE_OPALO.md) — юнит 2/3/4, ещё не разобраны до
оптимизационного ядра) или выбирать классический DLS — постановка (сумма
квадратов + линейные связи + активные границы) канонична для него;
(б) [REVERSE_MAP](REVERSE_MAP.md) фиксирует DLS/симплекс в SIM/VP-семействе
(`SIM.TRA` EPS/DMIN/DMAX — поисковые параметры).

## 3. OPALANG.DOC — входной язык

### 3.1. Вердикт

**OPALANG — декларативный язык ЗАДАНИЯ ДАННЫХ (assignment-DSL), не макро-язык
и не процедурный язык.** Каждый функциональный блок имеет СВОЮ реализацию:
свой список идентификаторов/марок, типы и размерности (скаляр/1D/2D-массив);
синтаксис общий (OPALANG.DOC:8–15). Реализация = настроечная таблица
транслятора `*.TRA` + контекстная помощь `*.OH` + шаблон `FORM.<расширение>`
(см. §1.8, §2.3). Макросов, управления порядком вычислений (кроме выражений),
подпрограмм НЕТ.

Связка с модулями:
- **OPALTRAN.EXE — общий транслятор** всех реализаций (настроечные таблицы
  `.TRA` — из OPAL.DOC:154 «настроечные таблицы транслятора с входного языка»;
  спавнится работами OPT/OPTW — REVERSE_OPALO §1; строка «PLIOPG» внутри
  OPT.TRA — вероятно внутреннее имя транслятора [НЕПРОВЕРЕНО]);
- **OPALEDIT.EXE — средний текстовый редактор с встроенным транслятором**
  (вызов из работ, F4-трансляция, F1-помощь, F8-SaveAs — OPALANG.DOC:190–249;
  в работе «Формирование» — через меню «Входной язык», OPAL.DOC:444–458);
- **OPALCALC.EXE — калькулятор** (глобальная клавиша «4-Калькулятор»,
  OPAL.DOC:224) — разделяет с языком арифметику (+ − * /) и идентификаторы,
  но отдельная программа расчёта, не транслятор заданий.

### 3.2. Грамматика (сводка из OPALANG.DOC:24–188)

```
текст      ::= оператор (";" оператор)*            ; разделитель — ";"
оператор   ::= левая "=" правая
левая      ::= идентификатор [ "(" индекс-список ")" ]
             | идентификатор "(" индекс-список "," столбец ")"   ; 2D: столбец слева
правая     ::= выражение ("," выражение)*          ; для 2D — элементы в ( )
индекс-список ::= индекс ("," индекс)* | "*"
индекс     ::= целое | целое "-" целое             ; перечисление или диапазон
выражение  ::= константа | марка | идентификатор
             | выражение ("+"|"-"|"*"|"/") выражение   ; без приоритетов задано? — [только перечислены операции]
константа-целая  ::= ["+"|"-"] цифра+
константа-вещ    ::= ["+"|"-"] (основная [ "E" порядок ] ), основная ::= [цифры]"."[цифры]
константа-симв  ::= имя из каталога (напр. марка стекла) ; список уникален для реализации
идентификатор   ::= буква/цифра, длина ≤ 6
комментарий     ::= "!" … "!"                       ; многострочный, не внутри оператора
```

Правила массивов (OPALANG.DOC:127–177):
- индексы обычно с 1, «в специально оговоренных случаях» с 0;
- `(X)` — список индексов может опускаться: количество элементов = числу
  выражений справа;
- **«размножение последнего значения»**: если элементов слева больше, чем
  выражений справа — последнее значение присваивается всем оставшимся
  (`X=204.5,18.4,-0.863,15` → хвост = 15);
- диапазоны и перечисления: `X(3,7,9,15-19)=0.7,19.4,23,0` (0.7→X3, 19.4→X7,
  23→X9, 0→X15..19 — снова размножение);
- 2D: номер столбца слева, элементы столбца справа в скобках:
  `Z(1,2)=(1.83,1.0,1.536,1.0,1.374)`, `C=(2,6,10),(4,7,3),(5,9,13)`;
- арифметика в правых частях: `R(5)=2.*R(4); D(7)=D(6)+D(4);` — ссылки на
  РАНЕЕ определённые данные (вычислимые значения, не ленивые).

Ограничения/умолчания: данные не указанные явно — принимают умолчания
реализации; транслятор проверяет синтаксис, допустимость идентификаторов и
выражений, ошибки — окно с номером строки и текстом.

### 3.3. Примеры реализаций (живые файлы)

```
FORM.OPT:  PAR(*)= C ;  EQF(*)= VG0 ;  MF(*)= DSA,DYA, DPA, DYM, DYS,DXS, ZM,ZS, DVL ;
FORM.OPW:  PAR(*)= C;  EQF(*)= VG0;  MF(*) = CWZ;
FORM.SIM:  MOD(*)= ; PAR(*)= ; V0= ; Dmin(1- )= ; Dmax(1- )= ; S'min= ; PM(1)= ; RM(1)= ;
FORM.VP:   MP(*)= T,D;   MF(*) = dw1/0****,W/0***;
OPALOPT:   MF(1-4)=DYA,DYM,DYS,DXS; MF#(1-4)=5,55,10,1; MFW(1-4)=1,0.1,0.2,0.1;
```

(строчные `dw1`/`W` в FORM.VP и `Dmin` в FORM.SIM — регистронезависимость
идентификаторов; в OPT.TRA заглавные — [таблица хранит канонический вид].)

### 3.4. OPTZ ↔ данные *.VP — гипотеза снята

OPAL.DOC:168 относит расширение `.VP` к текстам входного языка работы
VP («Влияние параметров», MAN_VP.DOC) — не к OPTZ. OPTZ в прочитанных DOC
не имеет явного файла данных/EXE; его носитель — [НЕИЗВЕСТНО] (возможно,
поздний релиз OPALO/OPTZ-вариант OPALOV.EXE — «OPALOV» = OPT-Variable? —
гипотеза, требует реверса).

   поперечные 0.01, CWZ в λ).
2. **Парсер входного языка** (подмножество OPALANG): операторы
   `идент(индексы)=выражения;`, индекс-списки `(3,7,9,15-19,*)`,
   размножение последнего значения, минус-марки, комментарии `!…!`,
   арифметика `+ − * /`, идентификаторы ≤6. Реестр идентификаторов — из
   OPT.TRA (§1.8; включает недокументированные N/DNR/NSC/AL — включить как
   «unknown, reserved»).
3. **Разбор марок**: `имя/LJIS(A)`; мультипликация `*` по фактическим
   размерностям (число λ = NLA, пучки, RAYA/RAYM/RAYS/RAYT), `?`→умолчание,
   `'`→L(2)−L(1)-разности, `"`→вторичный спектр (формулы §1.9);
   групповая марка разворачивается, повторная — корректирует параметры
   (правило примера 14–15: последняя спецификация выигрывает, неуказанные
   значения сохраняются прежними).
4. **Merит-функция**: `Φ = Σ офᵢ² + Σ шфⱼ²` — считать штрафы частью
   objective (внутренние t/g).
5. **Ограничения**: EQF — мягкие равенства с допуском (допуск в нормах;
   VG0 умолчание ±2 %); INF — односторонние с допуском INFT; границы
   параметров — отдельно по типам (C/D/ES/SO/SI/SD), правило знака толщин
   `D·N/|N|`.
6. **Связи** — линейные коэффициенты CC; связанные параметры не в PAR;
   допустимые пары — 6 типов §1.4 (проверять при валидации).
7. **Метод**: документация метод НЕ даёт (§1.12) — реализовать
   **DLS (damped least squares / Levenberg–Marquardt)** как канонический для
   суммы квадратов + аctive-set «метод исключения» для границ +
   модифицированные штрафные функции (пересчёт t,g по циклам — внешние
   итерации). Численные параметры цикла/шага оставить конфигурируемыми;
   сверять поведение с OPALO.EXE при будущих волнах (юнит-2 OPALO —
   кандидат на оптимизационное ядро, REVERSE_OPALO §2).
8. **Лимиты** (валидация): NPAR ≤ 64 (свободных), NMF < 200 марок,
   NEQF ≤ 20; RAYA/M/S/T ∈ 1..4; NFRQ ∈ 1..4; SECT ∈ (0,90), умолчание 45.
9. **Операнды**: реестр вычислимых характеристик — параксиальные
   (V0/VG0/SG/SG'/DSG'/SP0/SP0'/L/LS'/LS/LSS'/OP) уже есть в
   `domain/calculations.py` (§19.3.2); аберрационные марки — поверх
   `analysis/aberrations.py` (DYA/DSA/DYM/DYS/DXS/DYT/DXT/DIS/DIS%/DVL/DVL%/
   ZM/ZS/AST/FCM/DPA/ZA/DSP/DSP' — все вычислители есть, §19.3.3); CWZ —
   `analysis/zernike.py`; DE/AS — габариты; ID — светораспределение
   (§19.3.1); MTF-операнды — `analysis/diffraction.py` (20 частот REVERSE_OPALO).
10. **Диагностика/мониторинг**: лог по циклам/шагам: Φ, штраф, вклады
    операндов (диаграмма вкладов), активные границы — соответствует
    графическому монитору OPT (§1.12) и упрощает сверку с OPALO.

## 6. Воспроизводимость

- Конверт: `py analysis/_tools/doc2txt.py [имена…]` → `C:\tmp_optdoc\*.txt`
  (cp866→UTF-8; инструмент добавлен в коммит).
- Токенизация .TRA: `py -c` + regex `[A-Za-zА-Яа-яЁё0-9%#'"<>*.-]{2,}` по
  cp866-дампу (см. историю сессии); файлы `extracted/opal_okb/{OPT,OPS,SIM,
  TEX,VP,VPA}.TRA`, `FORM.{OPT,OPW,SIM,VP,TEX,VPA}`.
- OPT.OH/OPW.OH — LZ-сжатые страницы справки (фрагменты текста узнаваемы:
  « - EQF, EQF#, EQFS», «ВНИМАНИЕ !», «являются ОБЯЗАТЕЛЬНЫМИ»); декодер —
  будущая волна (в C1 не требуется: текст дублирован OPALOPT.DOC).
- Числа строк в цитатах — строки UTF-8 конверта (= CP866-строки).

**Вердикт C1: досье закрыто.** OPALOPT.DOC разобран полностью (постановка
критерия, все операторы/марки, границы/связи/штрафы, OPTZ, сеанс);

НЕ является). Словарь §19 дополнен 17 терминами оптимизации. ТЗ для
optimization.py (волна 9) — §5.
