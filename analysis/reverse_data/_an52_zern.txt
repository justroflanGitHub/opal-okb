956 ветствующей  составляющей волновой аберрации ( аберрации данного 
957 типа) для луча, проходящего через верхний край зрачка.
958      Каждый зональный  коэффициент имеет марку C x IJ,
959          где х - степень разложения по хроматизму,
960              I - степень разложения по радиусу на зрачке,
961              J - степень разложения по азимуту на зрачке.
962      Вывод полученных коэффициентов производится при выполнении
963 первого пункта меню работы.
964  Номер пучка (точки поля) задается в окне EDIT.
965      В текстовом  виде производится вывод значений коэффициентов
966 зонального разложения функции волновой  аберрации .
967      В графическом режиме  производится  отображение  гистограмм
968 коэффициентов зонального разложения волновой аберрации (Абсолют-
969 ный) или гистограммы вклада в волновой критерий  аберраций  раз-
970 личных порядков (СКВ).
971      Установка вида гистограммы производится в поле "Вид отоб-
972 ражения" окна EDIT.
973      Цвет коэффициента определяется по максимальному вкладу дли-
974 ны волны в этот коэффициент,  справа в подокне для коэффициента,
975 на который указывает стрелка, выводится гистограмма его разложе-
976 ния по хроматизму, переход в подокно и обратно производится кла-
977 вишей "TAB". Стрелка перемещается клавишами движения курсора.
978      Клавишей "DEL"  можно  обнулить текущий коэффициент и таким
979 образом вести дальнейший анализ без учета удаленного коэффициен-
980 та.
981      В  информационном подокне выводится значение коэффициента и
982 для справки значение полихроматического волнового критерия.

984      5.2. Глобальное полихроматическое описание аберраций.
985 
986      При глобальном полихроматическом разложении волновая  абер-
987 рация  представляется разложением по ортогональным  полиномам от
988 относительной координаты на предмете, полиномам Цернике от кано-
989 нических полярных координат на зрачке и ортогональным  полиномам
990 от спектральной координаты.
991      Каждый глобальный коэффициент имеет марку C x K I J,
992          где х - степень разложения по хроматизму,
993              K - степень разложения по радиусу на предмете,
994              I - степень разложения по радиусу на зрачке,
995              J - степень разложения по азимуту на зрачке.
996      Вывод полученных коэффициентов производится при выполнении
997 второго пункта меню работы и только в текстовом режиме.

999 фициентов:
