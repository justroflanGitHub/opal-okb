# FORMULAS — справочник формул OPAL-OKB

Формулы расчётного ядра и реверснутые конвенции OPAL-PC. Каждая — с указанием
источника (досье `analysis/REVERSE_*.md` / код порта).

---

## 1. Геометрическая оптика (ядро)

### Продвижение луча до сферической поверхности
Длина сегмента от предыдущей точки до сферы радиуса `R = 1/A`:

```
L_s = (cos − √(cos² − A·D)) / A − r·d̂          (сфера)
L_s = −dot(r, d̂)                                (плоскость, A ≈ 0)
```

где `D = A·|r|² − 2Z`, `cos = d̂·n̂`. *(REVERSE_OPALDIS §M.1)*

### Преломление / отражение
```
Закон Снеллиуса (векторный):  d′ = η·d + (η·cosθᵢ − cosθₜ)·n̂ ,  η = n₁/n₂
Отражение:                    d′ = d − 2(d·n̂)n̂
```

### Параксиальный расчёт (y-nu)
```
y′ = y + d·u ;    n′u′ = nu − y·Φ ,   Φ = (n′ − n)/R  (сила поверхности)
f′ = −1 / (Π телескопических сил)                    (для сложных систем)
```

## 2. Волновая аберрация и марш-конвейер OPAL

### Каскад W₂ (OPL-аккумулятор per-surface)
```
W₂ = (W₂ + L_s) · head ,     head = n_пад / n_прел
```

### Микс записей (0x9497)
```
rec_k = (v_k + c₀) · rec_k · head + v_k · W₂
```
где `v_k` — наклоны из λ-структуры, `c₀ = [2d6e]`. *(OPALDIS §M.1)*

### Рекуррентность записей (0x94cc), per-surface
```
(x, d) → (−A·x − d, x)                    (преломление)
(A, B) → (−cos·(B + c·A), cos·A)          (зеркальная ветка 0x968d)
```

### Замыкание per-surface (0xd074)
```
W₂ += (B₃X·X² + 2·B₄X·X·Y + B₄Y·Y²) · head / 2
```

### Опорная сфера волновых
- Дальнее изображение: сфера с центром в точке Гаусса, вершина — центр
  выходного зрачка *(GFIX P4)*
- Мнимое изображение (`L_p < 0`): опорная плоскость — вершина последней
  поверхности; κ-таблицы `VIRTUAL_WAVE_KAPPA` *(GFIX R1)*

## 3. Конвенции печати OPAL

### Осевой веер
- Дальний предмет: запуск по высоте `zone·Ax` параллельно оси
- Ближний предмет: `Ax = sin NA`, запуск по углу `arcsin(zone·NA)` от точки
  предмета *(GFIX P6)*
- Печатная зона кромки з.1.0 может браться с предела трубы `h*` или
  зеркального прохода (OD2-веер) *(OPALDIS §M.5, GFIX §EDGE)*

### Продольные аберрации (дптр)
```
дптр = 1000 · (1/L′_зоны − 1/L′_паракс) ,  длины от плоскости ВЫХОДНОГО ЗРАЧКА
```
*(GVERIFY §2.2)*

### Поперечные аберрации (гр.мнсек)
```
угол = atan2(Δy, L′) из ЦЕНТРА ВЫХОДНОГО ЗРАЧКА на точку луча в плоскости Гаусса
печать: DD.MMSS (градусы.минуты-сотые)
```
*(OPALDIS OD3)*

### Метка Tg′×100 в TABOC2
- Дальнее изображение: `|H′ ЗР|` в мм — модуль высоты зонального луча
  в плоскости выходного зрачка
- Ближнее изображение: `−100·tg u′`

### Зрачковые координаты
```
H ЗР = зона · Ax (мм) ;   Н ЗР (ближний) = 100·tg(arcsin(zone·NA))
```
*(REVERSE_NZR, GVERIFY §2.5)*

### λ-закон печати (эмпирика E2)
```
λ(z) = 1 − (q₀ + q₁·z²)·z²      — семейства печати Tg′·λ, попер·λ²,
прод(дптр) = λ·[1000/(L − sP′) − 1000/(L_p − sP′)]
```
*(GFIX §4.3(vii), EDGE2_PRINT_LAMBDA)*

## 4. Оптимизация (ЛАП/GTISL)

### Нормальные уравнения Маркардта
```
(JᵀJ + λ·diag(JᵀJ)) · ΔP = −Jᵀ·r
```
- якобиан — центральные разности `P ± DP0`
- лимитер шага `|ΔP| ≤ 10·DP0`, до 15 бисекций линейного поиска
- λ-адаптация: рост при неудаче (÷… ×), падение при успехе
- границы `pmin/pmax` — штрафами `F = min(0; (X−t)·g)²`, не clamp
*(REVERSE_LAP §9, analysis/optimization.py)*

## 5. ГОЭ-голограммы

### Эффективная кривизна
```
C_eff(λ) = κ(λ) · C ,     κ(λ) = κ₀ + κ₁·(λ − λ₀)
```
GTIE00: `κ = 1.089185 + 5.27e-4·(λ − 4.25)`, λ записи HeNe `0.6328` мкм,
элемент **трансмиссионный** (зеркальная трактовка → MISS).
*(REVERSE_GOE_MODEL, domain/calculations.GOE_KAPPA_LAW)*

### Replay-условие
```
δ = rec₀ · λ₀ / λ        — фаза решётки на длине волны расчёта
```

## 6. Дифракция (уровень-2)

```
ФРТ = |FFT(W · зрачок)|²                (амплитуда чистой апертуры,
                                          центральное экранирование учитывается)
ЧКХ = |FFT(ФРТ)| ;  сечения: меридиональное (ν∥Y), сагиттальное
ν_c = D / (λ·f′)                         (частота среза)
Штрель: S = exp(−(2πσ)²)  (Марешаль)  |  точный: пик ФРТ_аберр / пик ФРТ_идеал
```
*(REVERSE_OPALO, analysis/psf_mtf.py)*

## 7. Единицы OPAL

- «гр.мнсек» — градусы + минуты/100, формат `f12.6` (напр. `-36.000000`)
- мм ↔ дптр: `дптр = 1000/мм` (положения зрачков, полей)
- tg×100 / tg′×100 — нормировка наклонов главного/зонального лучей
- Зоны зрачка равной площади: `1 / 0.866 / 0.707 / 0.5`
*(REVERSE_NZR, analysis/units.py)*
