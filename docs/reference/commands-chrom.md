## Параметры и результаты

### chrom.opal

OPAL-режим хроматизма: повторная трассировка с λ помеченных поверхностей; таблица TABAX3

**Returns:** {wl_main, mode, field_y, rows, text} — строки TABAX3 + текстовый формат OPAL

| Имя | Тип | Обяз. | Умолчание | Choices | Описание |
| --- | --- | --- | --- | --- | --- |
| `file` | `str` | — | `null` | — | путь к файлу системы (.opj/.lbo/.json) |
| `system` | `str` | — | `null` | — | имя системы в контексте REPL |
| `lbo_index` | `int` | — | `0` | — | индекс записи в .lbo (если file указывает на библиотеку) |
| `lbo_name` | `str` | — | `null` | — | имя .OPJ-записи в .lbo (приоритетнее lbo_index) |
| `wl_main` | `float` | — | `null` | — | основная λ пары (мкм); по умолчанию — основная λ системы |
| `wl_flags` | `list` | — | `null` | — | флаги волн по поверхностям: 0 — основная λ, int ≥ 1 — индекс λ системы (1-основной), float > 0 — λ мкм; по умолчанию — Surface.wl_flag / fallback по всем λ |
| `field_y` | `float` | — | `null` | — | поле главного луча; по умолчанию — максимальное поле системы |
