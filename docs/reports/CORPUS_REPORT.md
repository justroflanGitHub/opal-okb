## Топ аномалий (полный разбор — CORPUS_ANOMALIES.md)

1. **31 US-система: efl ровно 0 при корректном L** (USLENS 17, USBINOCL 8, USREPROD 3, USMICRO 1,
   LENS_SPC 1) — стёкла не декодированы (`glass=''` → n≡1 → рефракции нет). Проверено на
   USLENS[30] GAUSS F'=100. Один offset блока стёкол — минус 31 аномалия.
2. **17 систем: L=0, efl~1e-270, Seidel NaN** (RUSSAR 7, MICROLEN 7, LENS 3) — блок толщин не найден
   (layout кода заголовка); сюда же открытые вопросы LBO_FORMAT (Цуканова, код [0x36]=2).
3. **Телеобъектив-550** (LENS[67]): расчёт −41 — стёкла съехали на позицию (изображение «в стекле»);
   кандидат на новый инвариант декодера. **Инфракрасный f'=75** (LENS_SPC[3], расчёт 170) — известный
   код [0x36]=3, подтверждён сканом.
4. **Афокальные BINOCUL (22):** efl 1.6·10⁶…3.9·10⁷ мм, f# до 10⁷, продольные аберрации до 5·10⁶ мм —
   норма физики, efl неинформативен; нужен afocal-режим отчёта.
5. **Стекло-заглушка «0» (33 системы):** n линзы неверен, f' обычно в норме, Seidel недостоверен.
6. **Единичные:** USLENS[46] — 1 поверхность у «1L»-системы; USLENS[191] SPEED F'=1 → 104 (err 10326%);
   Окуляр симметр f'=33 → 6.3 (6 поверхностей вместо 8).

## Выводы о готовности порта

- **Конвейер:** готов к массовым прогонам — 0 крешей на 612 системах, ~1 мс/система, отказы
  изолируются по этапам (`--limit` для тестов, JSON schema 1 стабильна, 8 тестов).
- **Декод:** ~92.2% систем численно корректны; узнаваемые кластеры отказов локализованы (2 layout-класса
  + смещение блока стёкол) и чинятся точечно, без общего ретроспекта.
- **Физика:** параксиал/Зейдель/TABOC1 согласованы с каталогом там, где декод корректен (393 системы
  в 1% по f'; гидро-конвенция и US F'=1 подтверждены) — ядро порта воспроизводит OPAL-PC на корпусе.
- **Приоритеты починки:** (1) US-блок стёкол → +31 система; (2) layout-коды руссаров/микролен → +17;
  (3) afocal-режим для биноклей; (4) инвариант «последняя поверхность несёт стекло» в сканер
  (`--strict` — перенести детекторы аномалий в статус систем).
