## Правки парсера волны 3 (analysis/golden_verify.py, обратно совместимо)

Все правки — разбор НОВЫХ форматов печати; сравнительная семантика
(конвенции, допуски, знаковые правила) не менялась. Регресс: старые 43 —
байт-в-байт (см. таблицу выше), format-тест wave2 починился, новых
format-падений нет.

- **N1. Слитые соседние числа в «Габаритах пучков» (DEM1)**: Sp и Sp′
  печатаются без пробела — токен «-23.203-12678.780». Новый токенизатор
  габаритной строки `_gabarit_cells` (атом = число, включая слитые пары,
  либо звёздный прогон) заменяет `row.split()`: слитый токен даёт ДВА
  значения потока, позиция полей не сдвигается.
- **N2. Звёздное заполнение полей (LEXA23, N=0)**: «********************»
  на месте Sp/Sp′. Прогон звёзд заменяет столько полей «Положения зрачков»,
  сколько меток Sp/Sp′ (колонки 39/50) он накрывает; значения None → SKIP
  в сверке (иначе Sp′ ложно сверился бы с колонкой виньетирования;
  `ValueError: could not convert '*' to float` устранён).
- **N3. Компактная раскладка хвоста TABOC2 (DEM, LEXA23)**: при пустых
  колонках волн пара (неизопл, Н ЗР) упакована на поле левее — Н ЗР на
  месте изо (правый край 48), изо с краем 38; признак — пустые колонки
  [38:40). Без этого h_zr=None → сшивка зон по порядку.
- **N4. Точная инверсия «Н ЗР → зона» (LEXA23 na≈1.0, DEM na≈0.95)**:
  zone = sin(arctan(Н ЗР/100))/NA вместо линейной hzr/(100·NA). Линейная
  аппроксимация ломается при NA→1 (LEXA23: Н ЗР з0.707 = 99.999 линейно
  давал з1.0; DEM: 90.47 → з1.0 вместо з0.707). На малых NA (все старые
  системы) тождественна — старые 43 не изменились.
- Проверено без правок (парсер справился): дубль секции «Аберрации осевого
  пучка» (GUTAN4 — 1×«Габариты»+2×осевой; LEXA21/G1 — 2 вхождения):
  строки перезаписываются по тем же ключам, двойных вердиктов нет.
- Замечено, НЕ правилось (без влияния на вердикты): слипшаяся печать
  «-11.202431622.6200» (LEXA23 з1.0, изо −11.2024 + Н ЗР 31622.6200 без
  разделителя) разбирается в мусорные wave[2]/iso, но h_zr=None → строка
  сшивается порядком зон → ровно з1.0 (верно); у DEM в строках з1.0/з0.866
  Н ЗР (300.37/144.17) стоит в колонке изо — сшивка по порядку совпадает
  с Н ЗР-сшивкой, вердикты те же.
