## Ключевые решения

- **Пины старых категорий**: trace/beam/vign/tables и aber/chrom/seidel/adv
  запинены тест-модулями Волн — новые пакеты 16/17 ушли в префиксы
  `tracex`/`aberx`, пины не тронуты. Проверка пинов категории обязательна перед
  добавлением команд.
- **OPJ-раундтрип теряет field_points** — все поле-зависимые тесты/smoke
  используют .json-демо.
- **Композиция без новых ядер**: новые пакеты вызывают движки analysis/domain/
  catalog и сестринские команды через `registry.execute` (closure-реестр);
  живые системы передаются через `ctx.put_system` под служебными ключами
  с уникальными суффиксами.
- **Метрика чувствительности к наклону/децентру**: RMS пятна чётна — использовано
  смещение центроида (boresight) по соответствующей оси.
- **Инвариант счётчика**: `REGISTRY_TOTAL_COMMANDS` в `tests/test_commands_builtin.py`
  пинует 506 с по-пакетной раскладкой; smoke-инвариант требует smoke-записи для
  всех covered-категорий.
