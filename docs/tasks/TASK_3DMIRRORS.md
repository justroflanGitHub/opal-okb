# TASK_3DMIRRORS: 3D-визуализация — зеркальные поверхности

## Контекст
visualization3d.py: Visualization3D + _GLWidget (OpenGL). Зеркала рисуются
золотым кольцом (_draw_surface: is_reflective → golden ring, _draw_surface_ring
с is_mirror=True рисует front+back arcs). Замечание после Strehl-задачи:
«у зеркальных...» (обрезано) — есть известные тонкости зеркал в 3D.

## Задача — АУДИТ + ФИКС
1. **Аудит отрисовки зеркал** в visualization3d.py:
   - _draw_surface / _draw_surface_ring: геометрия дуги для R<0 vs R>0,
     полупрозрачность подложки зеркала (не должно просвечивать насквозь)
   - _draw_glass_volume: не должен рисоваться ДЛЯ зеркал (после отражения
     среды нет) — проверить, не рисуется ли объём «стекла» за зеркалом
   - _trace_rays: 3D-лучи после зеркала — правильно ли отражаются
     (оптика: domain/ray_tracing или analysis/ray_tracing.py), направление
     оси z после отражения
   - Тени/нормали: подсветка зеркальных сегментов
2. **Тест-система**: domain/models._demo_mirror (уже есть!) — создать скриншот
   offscreen (QT_QPA_PLATFORM=offscreen, grab() → PNG в /tmp) — до и после фикса.
   Сравнить визуально по описанию в вердикте (пиксели считать не обязательно,
   но проверить: золотое кольцо есть, объём за зеркалом отсутствует, лучи
   отражаются вниз/вверх корректно)
3. **Реальные зеркально-линзовые**: LENS_SPC.LBO «Инфракрасный з-л» (если декодер
   помечает зеркала; если нет — отметить в вердикте, НЕ чинить декодер тут)
4. Фиксы — точечные, стиль файла сохранить.
