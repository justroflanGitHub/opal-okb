# TASK_3D_VIZ — 3D-визуализация: интеграция OpenGL-вьюера, хроматические лучи, Strehl в GUI

**Проект:** OPAL-OKB (реимплантация оптического САПР OPAL-PC, PyQt5). Ты в изолированной копии, ветка `feature/3d-viz` (уже создана и активна, база — свежий main `de883be`: registry-506, golden-44, corpus v1+v2 влиты). 

**Контекст:** 3D-виджеты точечных данных ГОТОВЫ (spot 2D/3D-переключатель, PSF/wavefront 3D — `gui/widgets/`, контрактные тесты `tests/test_{spot,psf,wavefront}_3d.py` зелёные, паттерн placeholder «нет данных» отработан). Движок Strehl ГОТОВ (`analysis/strehl.py`). OpenGL-вьюер хода лучей СУЩЕСТВУЕТ, но **не интегрирован** (`visualization3d.py` в корне — QOpenGLWidget, трассировка системы; тесты `tests/test_viz3d_mirrors.py` + GL-stub `tests/_viz3d_glstub.py`). Исторический план — `docs/tasks/TASK_3D.md` (частично устарел — сверяйся с кодом, не с ним).

**Цель:** пользователь видит в приложении: (1) строку Strehl в панели результатов, (2) окно 3D-хода лучей с тумблером «лучи по λ» (цвет луча = цвет длины волны), с честным fallback при отсутствии PyOpenGL.

## План (пакетами, атомарные коммиты)

1. **A. Инвентаризация** (без кода): прогнать `tests/test_viz3d_mirrors.py` + `test_*_3d.py`; снять API `visualization3d.py` (что умеет: сцена/лучи/камера/rotate); найти точки интеграции в `main.py` (тулбар/меню, кнопка-прецедент `btn_wf_3d` ~main.py:957) и панель результатов (~ResultsPanel). Краткий план-файл `docs/tasks/3D_VIZ_NOTES.md` с gaps. Коммит.
2. **B. Strehl в GUI**: строка `<Strehl: 0.847 (σ=0.052λ, Марешаль)>` + tooltip (точный vs Марешаль, validity good/marechal_limit/invalid, полихроматический по λ с весами). Источник — `analysis/strehl.py` (дополнять ТОЛЬКО его, если не хватает полихрома; остальной `analysis/` не трогать). Подключение в `_refresh_ui` рядом со spot-результатами. Тесты: offscreen, на демо-ахромате 0 < S ≤ 1, Марешаль ≈ точный в разумном допуске, полихром ≥ моно-минимума. Коммит.
3. **C. Интеграция 3D-вьюера**: кнопка «3D-ход лучей» (меню «Вид»/тулбар) → окно с `visualization3d.py`-виджетом, подача текущей системы + вееров лучей по полям (образец данных — plot.layout / trace-команды реестра, ЧТЕНИЕМ, без правок реестра). Нет PyOpenGL → кнопка disabled + tooltip «pip install PyOpenGL» (детект-паттерн `requires_pyopengl` в conftest). Тесты: offscreen через GL-stub (прецедент test_viz3d_mirrors), окно открывается/закрывается, сцена не пуста. Коммит.
4. **D. Хроматические лучи**: тумблер «Лучи по λ» в окне 3D: цвет луча = цвет спектральной линии (палитра `utils/spectral_lines.py` уже в репо — единый источник); моно (основная λ) ↔ полихром (все рабочие λ с весами). Если в GUI есть 2D-разрез хода лучей — тот же тумблер и там (по итогам A). Тесты: число цветов = числу λ, toggle переключает набор отрисованных лучей. Коммит.
5. **E. Финал**: полный `py -m pytest -q` зелёный (в т.ч. все placeholder-контракты 3D-виджетов живы); CHANGELOG `[1.32.0]`; строка в README; отчёт `docs/tasks/3D_VIZ_REPORT.md` — что вошло, что отложено и почему (осознанные решения фиксируй, не молчи). Коммит.
