# TASK_CI_SKIPS.md — CI-зелёность: скипы для тестов с локальными данными

**Контекст.** GitHub Actions (.github/workflows/tests.yml) на windows-latest падает 51 тестом: на runner нет `extracted/` (889 стёкол FIL, .OPJ-архивы, LBO — в .gitignore осознанно, ~сотни MB) и других локальных ресурсов. Golden bank уже добавлен в git (15c1ae3) — его тесты работают. Полный лог упавших: `$env:TEMP\ci_fail.log` (уже скачан, формат: префикс `test\tRun pytest...` + FAILURES-секция с трейсбеками). Свежий прогон: `gh run view 39869386094 --log-failed`.

**Цель:** тесты, которым нужны отсутствующие на CI ресурсы, должны SKIP с внятной причиной, а не FAIL. Локальный прогон (данные есть) остаётся 1542 passed.

## Что сделать

### 1. Единый helper в tests/conftest.py (single source of truth)
Детекторы наличия ресурсов + маркеры, например:
```python
EXTRACTED = Path(__file__).resolve().parent.parent / "extracted"
HAS_EXTRACTED = EXTRACTED.is_dir()   # + более точные: HAS_FIL, HAS_OPJ_DIR, HAS_LBO по фактическим путям из тестов
requires_extracted = pytest.mark.skipif(not HAS_EXTRACTED, reason="нет extracted/ (локальные данные, не в git)")
```
Точность: если у теста зависимость конкретная (только FIL-стёкла) — использовать конкретный детектор, не общий. Имена — по смыслу ресурса.

### 2. Разнести скипы по списку FAIL (51)
Каждый упавший тест из ci_fail.log:
- определить какой ресурс ему нужен (по трейсбеку и коду теста);
- пометить нужным маркером (класс/функция);
- тесты без данных-зависимостей (логические ошибки на CI — если найдутся) — НЕ скипать, а починить по-настоящему.
Файлы по списку: qa_v6_full.py, test_all.py, test_commands_builtin.py, test_commands_aber.py, test_commands_cli.py, test_commands_mcp.py, test_golden_*.py (если ещё падают), qa_critical.py, test_chromatism.py, test_beam_heights.py и др. — полный список из лога.

### 3. Правила
- НЕ трогать src/ — только tests/ и conftest.py.
- Скип — последняя мера: сначала проверить, что тест действительно про локальные данные (у CI данные недоступны по определению).
- Дубликаты детекторов запрещены: все пути/маркеры — только в tests/conftest.py, тесты импортируют.

### 4. Проверка
- `py -m pytest -q` локально: ≥1542 passed, новые скипы НЕ должны срабатывать (данные есть) — счётчик passed не падает.
- Смоделировать CI: временно переименовать extracted/ (или env-переменной, если сделаете переключаемое), прогнать затронутые файлы — падений нет, скипы сработали. Вернуть как было.
- Коммит в main: "test(ci): skip-маркеры для extracted-зависимых тестов (51 FAIL → skip)". НЕ пушить.
