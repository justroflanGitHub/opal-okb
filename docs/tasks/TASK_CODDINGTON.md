def coddington_trace(system, wl=None, field_y=0.0) -> dict:
    """Дифференциальный след Коддингтона вдоль главного луча.

    Возвращает:
      z_m, z_s      — меридиональный/сагиттальный фокальные отрезки (мм, от последней

def caustic_radii(system, wl=None, field_y=0.0, ray_halfheight=None) -> dict:
    """Радиусы кривизны каустических поверхностей 2-го порядка (мм).

      r_m, r_s        — меридиональный/сагиттальный радиус каустики (мм)

## Математика

### Коддингтон (классические уравнения, выверенные по реверсу)

Вдоль главного луча (field_y ≠ 0 — косой пучок; при field_y=0 дать осевой случай t_m=t_s=f').
Для КАЖДОЙ поверхности по ходу главного луча (использовать существующие
`_field_chief_ray` / трассировку главного луча — точка падения, косинусы падения/преломления):

- точка падения, нормаль N, углы: cos_i = |D·N| (падение), cos_r = |D'·N| (преломление)
- радиус r с ЗНАКОМ (выпуклость навстречу лучу)
- перенос от предыдущей поверхности: t вдоль луча (из трассировки)
- меридиональная рефракция (n'=n2):
  n'·cos²r/t_m' = n·cos²i/t_m + (n'·cos r − n·cos i)/r_sign
- сагиттальная:
  n'/t_s' = n/t_s + (n'·cos r − n·cos i)/r_sign
- Начальные условия: t_m=t_s=−∞ (плоская волна) → работать в обратных величинах
  (силы P=1/t) как OPAL (у него «углы» u — аналоги 1/h пропорций): аккуратно с
  нулевым стартом: стартовать с параксиального отрезка от входного зрачка.

Сверка с реверсом OPAL (обязательные соответствия, указать в docstring):
- выход Z'm = h/u отношение (0x1971D/0x19C15), знак − и ×n — отсчёт в оптических
  переменных; в порте — физические мм
- отсчёт от опорной плоскости: delta = z − img_z (0x19976: Z := z_ref − Z)

### Каустики

OPAL: R_m = A₂/u² (0x19739, показатель [0x2D8E]≈2), смешанная R_ms = A₂ms/(u_m·u_s²)
(0x197CD). В порте реализовать ЧИСЛЕННО-ДИФФЕРЕНЦИАЛЬНО (точнее слепого копирования):
- по вееру из 3 меридиональных лучей (h=0, ±δ; δ = ray_halfheight или 1% от зрачка)
  найти z_m(h) пересечений пар → параболическая аппроксимация z_m(h) ≈ z0 + h²/(2R_m)
  → R_m = δ²/(z(δ) − 2·z(0) + z(−δ)) · 2 — согласовать знак (каустика вытянута вдоль
  оси: положительный R — центр кривизны за фокусом)
- аналогично сагиттально (лучи ±δ в сагиттальной плоскости)
- r_rel = r/f'·100 (нормировка OPAL [0x3A10]≈100/f′)
- при вырождении (δ→0 шумы) вернуть None + method='numeric' с бо́льшим δ

## Тесты (tests/test_coddington.py, ОБЯЗАТЕЛЬНО)

1. **Сходимость с веером**: для систем из tests/fixtures (все .opj/.json фикстуры
   со сферической оптикой) при сужении веера: |z_m_coddington − z_m_fan| < 5%·|z_m|
   (веер 15 лучей сейчас в compute_field_aberrations). Астигматизм: совпадение знака
   и величины в пределах 10%
2. **Осевой случай**: field_y=0 → t_m == t_s == фокусное расстояние (до 1e-6 отн.)
3. **Каустики**: R_m > 0 для положительной линзы; симметрия z(δ)=z(−δ); в параксиальной
   зоне R растёт при закрытии зрачка (каустика сплющивается) — качественный тест
4. Регресс: pytest -q tests/ — ВСЕ зелёные, старые числа не тронуты
