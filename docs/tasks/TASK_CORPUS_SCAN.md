## Декомпозиция на 5 субагентов (ориентир — скорректируй по ходу)

1. **SA-1 сканер**: `scripts/corpus_scan.py` — CLI (`--lib <путь> --out <json> --limit N`), прогон каждой системы: загрузка → paraxial (EFL/BFD/f#) → seidel → taboc1 → зрачки; запись на систему: {имя, индекс, статус ok/fail, код ошибки, метрики}. Один JSON на библиотеку. Быстрый режим для тестов (`--limit 5`).
2. **SA-2 метрики**: `scripts/corpus_stats.py` — вход JSON → распределения: f' (гистограмма), число поверхностей, стёкла (топ), % успеха по операциям, отказы по кодам. Вывод: markdown-таблицы.
3. **SA-3 анализ аномалий**: по JSON найти топ-20 подозрительных (NaN/бесконечности, f'=0, отрицательный track, EFL расходится с ожиданием на порядки) — каждая: имя, что случилось, гипотеза (2-3 строки). Сверка f' порта против f' заголовка записи: таблица расхождений >1%.
4. **SA-4 тесты**: `tests/test_corpus_scan.py` — smoke на 5 системах реальной библиотеки (по абсолютному пути; нет данных → skip с reason), покрытие парсера аргументов, стабильность JSON-схемы. Не гонять полный корпус в тестах!
5. **SA-5 доки**: `docs/reports/CORPUS_REPORT.md` (итоговая карта: 612 систем, метрики SA-2, топ аномалий SA-3, выводы о готовности порта) + CHANGELOG `[1.30.0-corpus]` + строка в README (раздел Golden/verification: «corpus scan: 612 systems, X% paraxial OK»).

Ты: создаёшь R-files `docs/tasks/CORPUS_PLAN.md` (таблица подзадач/статусов — твой чекпойнт), раздаёшь, интегрируешь, коммитишь атомарно по подзадаче, в конце полный `py -m pytest -q` зелёный.
