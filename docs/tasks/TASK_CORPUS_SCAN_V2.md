# TASK_CORPUS_SCAN_V2 — Корпус волна 2: больше операций по тем же 612 системам

**Проект:** OPAL-OKB (реимплантация оптического САПР OPAL-PC). Ты в изолированном worktree, ветка `feature/corpus-v2` (уже создана и активна, базируется на main, где уже лежит корпус-скан волны 1: `scripts/corpus_scan.py`, `scripts/corpus_stats.py`, `tests/test_corpus_scan.py`, `docs/reports/CORPUS_REPORT.md`, corpus.json).

**Контекст:** волна 1 прогнала 612 систем LBO-архива через конвейер load→parse→paraxial→seidel→taboc1→pupils и сверила f'. Теперь — расширение конвейера НОВЫМИ операциями и метриками по тем же системам. Шаблоны, контракты JSON, правила отказоустойчивости и стиль уже есть в волне 1 — расширяй по образцу, ничего не изобретая заново.

**Цель:** `corpus_scan.py` умеет `--ops all|базовые|v2|список` (по умолчанию все), новые операции по каждой системе, `schema_version 2`, обновлённые статистика и отчёт `CORPUS_REPORT_V2.md` с распределениями новых метрик и топ-аномалиями.

## Новые операции конвейера (по каждой системе)

Для каждой — bool в `ops` + поля в `metrics` (None при отказе, ошибка — в `error`, конвейер не валится):

1. **`vignette`** — апертурные характеристики (по образцу таблицы TABBEA): виньетирование на макс. поле (верх/низ, %), положение выходного зрачка; поля — точки поля системы, если поля нет — одна осевая.
2. **`chief`** — аберрации главного луча на макс. поле: дисторсия (%), отрезки Z'm/Z's (астигматизм, мм) — если система полевая (поле > 0); иначе None-поля с ok=True (осевые — валидный случай, не ошибка).
3. **`spot`** — RMS пятна: полихроматический, на оси и на макс. поле (мкм; сетка по умолчанию из волны 1 не трогается — фиксированные параметры: 30×30, длины волн системы с весами).
4. **`mtf_geo`** — геометрическая ЧКХ (FFT гистограммы пятна): контраст на 30 и 50 лин/мм, тангенциальный, ось + макс. поле.

Если какая-то операция требует полярных настроек, которых в движке нет — НЕ выдумывать: пометить операцию как `unsupported` (bool None + error='unsupported') и задокументировать в отчёте. Пустышки-заглушки без реального расчёта запрещены.
