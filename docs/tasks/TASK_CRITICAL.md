## Справка по предметной области
- Осевой пучок: лучи через зрачок на оси, аберрации Δy' (меридиональные), Δs' (сагиттальные), W (волновая)
- Неизопланатизм: аберрация главного луча при смещении предмета (нарушение изопланатизма) — вычисляется как разность поперечной аберрации для малого смещения поля; в OPAL-PC это 4-й график рядом с Δy', Δs', W
- СКВ (RMS) волновой аберрации: среднеквадратическое отклонение W от среднего по зрачку
- Фокусировочные диаграммы: 5 точечных диаграмм при defocus = номинал, ±ΔS', ±2ΔS' (ΔS' — смещение плоскости установки)
- СКВ пятна: RMS_X, RMS_Y — раздельно по осям; Y_цэ — координата энергетического центра (центроида)
- PSF: функция рассеяния точки (дифракционная FFT)
