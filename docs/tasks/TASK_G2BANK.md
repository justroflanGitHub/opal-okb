## Проверенный рецепт на систему (из G2_NOTES)
```
boot (KEYRUS→OPAL.COM) → ENTER (Работа-RT) → F10 → бар активен
→ ENTER («Сист» → редактор METAPRN)
→ F2 → ENTER (Чтение) → BS×12 → <ИМЯ> → ENTER      # загрузка из OPAL.ARH
→ F10 (выход в MENUOPAL) → RIGHT RIGHT → ENTER («Анализ») → ENTER (Работа-RT)
→ '4' (габариты — ОБЯЗАТЕЛЬНО до аберраций)
→ '6' (аберрации осевого пучка)
→ F4 (протокол) → F9 (запись) → ENTER              # → RT__HHMM.PRN
```
- Оракул свежести: PROTOCOL.PRN 0 б → сессия свежая
- ENTER в диалогах иногда требует задержки ~2 с после набора букв
- Если диалог фризит — сырые сканкоды keybd_event + ALT-focus-трюк (_scratch_sdl.py)
- Каталог: если загрузка по имени капризничает — F9 «ФИЛЬТР:» в редакторе
