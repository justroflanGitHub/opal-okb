# TASK_G2BANK_BATCH2.md — Golden bank extension: 16 → 30-50 систем

**Контекст.** `scripts/g2bank.py` — готовый батч-генератор эталонных .PRN из оригинального OPAL-PC под DOSBox (рецепт откалиброван, автоповторы, запись в `analysis/reverse_data/golden/bank/` + манифест `analysis/REVERSE_G2BANK.md`). Сейчас в банке 16 .PRN (14 систем + 2 _stale). В `C:\GOLDEN_DOS` лежит 85 standalone .OPJ — 71 ещё не в банке.

**Цель:** ночной батч-экспорт ~30 новых систем → банк вырастет до 44-46 (в диапазон «30-50 систем» из README Phase III).

## Шаги

### 1. Фикс encoding-бага (main, файл scripts/g2bank.py)
При редиректе вывода в файл лог падает: `log()` печатает '→' (U+2192), а Windows-консоль — cp1251. Уже воспроизведено (UnicodeEncodeError, main→'автоповтор').
Фикс по-продакшн: в начале `main()` — `sys.stdout.reconfigure(encoding='utf-8', errors='replace')` (и stderr тоже). Никаких try/except вокруг print.

### 2. Очередь систем (30 имён)
Из `C:\GOLDEN_DOS\*.OPJ` исключить:
- 14 уже в банке: 121, GTIE00, HELIOS8, KURSOVIK, LAB6_GAS, OBEKTIV, OKULAR, OPAL3, OPTICS#1, PLIOPT, ST, ST4, S_KOND1, US00KI02
- 2 отклонённых ранее (см. REVERSE_G2BANK.md «Отклонённые»): GTIN05 (RT не даёт секций), YBBS77_ (зависает на RIGHT-пути)
Выбрать **30 имён**, стараясь покрыть разнообразие: не брать 30 подряд из одной «серии» (DEMON*, LEXA*, SERGEY* — брать по 3-4 максимум из каждой серии). Очередь записать в `analysis/REVERSE_G2BANK.md` новой секцией «## Волна 3 (батч 30)» списком.

### 3. Смоук (2 системы)
Запустить `py scripts/g2bank.py ИМЯ1 ИМЯ2` (foreground, с логом). Обе должны дать статус OK (или OK-NOAXIAL для простых систем — но тогда взять другую пару для верификации OK). Если смоук падает — разобраться (не более 2 итераций фиксов; рецепт НЕ менять, менять только обвязку).

### 4. Ночной батч (отсоединённо)
После успешного смоука запустить ОСТАЛЬНЫЕ 28 систем detached-процессом, который переживёт закрытие терминала:
```powershell
Start-Process -WindowStyle Hidden py -ArgumentList 'scripts\g2bank.py','ИМЯ3','ИМЯ4',... -WorkingDirectory <repo> -RedirectStandardOutput g2batch_night.log -RedirectStandardError g2batch_night.err.log
```
(лог в корне репо, добавить в .gitignore: `g2batch_night.*.log`). НЕ завершать процесс, НЕ ждать его окончания — просто убедиться, что процесс жив (Get-Process py / размер лога растёт), и зафиксировать в отчёте.

### 5. Коммит
В main: фикс g2bank.py + секция «Волна 3» в манифесте + .gitignore. Данные bank/*.PRN новых систем НЕ коммитить (это сделает координатор утром после сверки). CHANGELOG: запись про encoding-фикс. Не пушить.

## Правила
- Рецепт g2bank.py (последовательность клавиш, тайминги) — НЕ трогать.
- DOSBox-окно будет открываться/закрываться — это нормально, машина Михаила, не мешать пользователю нельзя, но минимизировать: WindowStyle Hidden для батча (сам DOSBox из conf стартует как есть — ок).
- Если обе смоук-системы дали OK и батч запущен — задача выполнена, отчёт: сколько в очереди, статус смоука, PID батча, путь лога.
