## Задача
1. Найди в OPALA_unp обработку ГОЭ-поверхностей: как gidx=0xFFFD влияет на
   преломление/отражение (дифракционная добавка? дисперсия λ/λ_rec?
   порядок +1/−1?). Ищи: сравнение gidx с 0xFFFD/−3 в цикле трассировки,
   вызовы вокруг λ-дисперсии (0ff9:0019), таблицы констант записи.
2. Восстанови ФИЗИКУ: голограмма = решётка с эффективной силой
   (∝ λ/λ_rec для holographic lens; внеосевая запись → two-wave superposition).
   Сформулируй модель OPAL (что он реально считает для луча на ГОЭ).
3. Имплементируй в порте: surface GOE (marker → тип), трассировка с
   дифракцией (порядок, λ-скейлинг), regression-тест против GTIE00
   (Sp′ сходится? осевые зоны против эталона, если есть .PRN).
4. Досье: analysis/REVERSE_GOE_MODEL.md — модель, формулы, адреса, статус.
