# TASK_GVERIFY: золотая верификация порта против банка .PRN (14 систем)

## Контекст
Волны G2/G2BANK закрыты: DOSBox-эталоны в `analysis/reverse_data/golden/bank/`
(14 .PRN: габариты + осевые аберрации, CP866-текст). Sanity US00KI02 уже совпал
с OPAL побайтово. Теперь ГЛАВНОЕ: сравнить РАСЧЁТ ПОРТА с OPAL по всем 14.

## Цель → analysis/REVERSE_GVERIFY.md + harness analysis/golden_verify.py
1. Парсер золотых .PRN: заголовок системы, секция габаритов (F/F'/SF/SF'/SH/SH',
   S/S'/S'G/V/SP/SP' параксиальная таблица), секция осевых аберраций
   (koop 1.0/.866/.707/.5/.0 → продольные дптр, поперечные гр.мнсек; вторая секция
   волновые/неизопл/Н ЗР/%). CP866 → UTF-8. Названия секций см. в самих .PRN.
2. Загрузка систем в порт: исходники — `C:\GOLDEN_DOS\*.OPJ` (82 файла; имена
   как в манифесте REVERSE_G2BANK.md). Порт: `lbo_io.load_lbo` / `decode_lbo_opj`
   (гальванически проверены на 612 системах) — подбери API загрузки OPJ → OpticalSystem.
3. Расчёт порта: параксиальные габариты (paraxial_trace / TABES-таблицы) +
   осевые аберрации (aberrations: продольные дптр / поперечные гр.мнсек,
   те же koop-кольца). Учти конвенции OPAL: дптр-знаки, гр.мнсек (units.py),
   Н ЗР — зрачковая координата (REVERSE_NZR).
4. Сравнение: на систему — таблица «величина | OPAL | порт | Δ | допуск».
   Вердикт: точное совпадение формата OPAL — 5 знаков (как в .PRN);
   допуск сверки: параксиалы ≤1e-4 отн., аберрации ≤1e-3 отн. (после выравнивания
   знаков/масштабов!). Итог: сколько систем зелёных/жёлтых/красных, топ-расхождения.
5. Тесты: tests/test_golden_verify.py — парсер + хотя бы 3 системы end-to-end
   (US00KI02 обязана быть зелёной — sanity). Полный pytest -q зелёный.
