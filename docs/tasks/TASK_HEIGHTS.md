# TASK_HEIGHTS: TABESB (световые высоты) + TABEAP (экранные зоны) — реверс §14.1

## Цель
Реализовать таблицы габаритных лучей из REVERSE_TRACE.md §14.1:

**TABESB** (1X,i3,f11.3,2f12.3,4f10.3), шапка «Световые высоты»:
колонки «Пов│осевой пучок│Верхний Нижний│Верхн.раб Нижн.раб│Верхн.отв Нижн.отв» —
высоты Y габаритных лучей НА КАЖДОЙ ПОВЕРХНОСТИ: осевой луч, верхний/нижний
предельные, верхний/нижний рабочие (по полю), верхнее/нижнее отверстие
(clear aperture = semi_diameter со знаком).

**TABEAP** (1X,i3,4f9.5,f9.4,2f8.3,2(1x,1a,1x,i3)), шапка «Относительные размеры
экранирования│смещение на экране│Виньетирование│Ограничения», ось «x y x y»:
экранные зоны для зеркально-линзовых систем с центральным экранированием.

## Тесты (tests/test_beam_heights.py)
1. Плосковыпуклая линза: высоты осевого луча монотонно убывают от semi_diameter
   к фокусу; верхн.отв = ±semi_diameter

3. _demo_mirror: осевой Y после зеркала убывает, знак меняется корректно
4. format_tabesb: ширины полей по формату (i3, f11.3, 2f12.3, 4f10.3)
5. tabeap: система без экранирования → нули; с obscuration_ratio=0.3 → размеры > 0
