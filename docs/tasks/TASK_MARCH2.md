# TASK_MARCH2: имплементация марш-рекуррентности OPAL — закрыть банк (основная модель)

## Цель
Симулировать марш-конвейер печати OPAL напрямую (не подгонкой): RED 4 → 0,
YELLOW 13 → ≤5, цензоры 307 GREEN целы. Все формулы уже реконструированы.

## Источник истины (читай ОБЯЗАТЕЛЬНО, всё есть!)
- analysis/REVERSE_OPALDIS.md §M.1–M.5 — ПОЛНЫЙ конвейер:
  - L_s = (cos−√(cos²−A·D))/A − r·d̂ (длина сегмента; плоский случай −dot)
  - W₂ = (W₂ + L_s)·head — каскад 0x9435
  - микс 0x9497: rec_k = (v_k + c₀)·rec_k·head + v_k·W₂; v_k = наклоны
    qword[head-структура+8+8(k−1)], c₀=[2d6e], записи [3c30+8(k−1)]
  - рекуррентность 0x94cc: (x,d)→(−A·x−d, x), зеркальная ветка 0x968d
    (A,B)→(−cos·(B+c·A), cos·A); экспорт 0x9627/0x9837 с вычетом
    qword[3d90+0x18(k−1)]/[3d98+…]
  - замыкание 0xd074 per-surface: W₂ += (B3X·X²+2·B4X·XY+B4Y·Y²)·head/2
  - вывод 0xcd62; KURSOVIK з.1.0 = W(h*=18.441824) предел трубы (пин-тест
    test_kursovik_march_tube_limit_ray, дискриминация источников)
- analysis/golden_verify.py — харнесс, допуски, цензоры
- Остатки: волновые з.1.0/0.866/0.707/0.5 (RED 4: −229.34/75.284/−71.321/
  67.727-семьи; YELLOW 13: 1.1e-3…2.2e-2) + прод/попер/Н ЗР мелочь (1e-3)

## Задача
1. Новый модуль **analysis/golden_march.py**: точная симуляция конвейера —
   семена записей rec_k (начальные значения/наклоны v_k из структуры λ-слота),
   per-surface цикл (L_s → W₂-каскад → микс → рекуррентность), замыкание,
   вывод. Зеркальные ветки для is_reflective. ГОЭ — по правилу GOE_MODEL.
2. Сверка с банком на ВСЕХ системах: каждый остаточный RED/YELLOW должен
   либо закрыться (симуляция = банк в допуске), либо получить точную
   причину (например: семя не извлекается статически — тогда локализуй
   структуру в дизасме).
3. Если симуляция подтверждена — замени эмпирику EDGE2_PRINT_LAMBDA
   физическим расчётом (q-пары должны исчезнуть); при переносе в порт
   (aberrations) — fix → regression-тест.
4. Цензоры: US00KI02/KURSOVIK/ST4/LAB6_GAS/GTIE00/OPTICS#1 + 307 GREEN.
