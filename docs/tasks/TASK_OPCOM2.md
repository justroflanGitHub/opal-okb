## ЦЕЛЬ (главное): золотой запуск → эталонные .PRN
1. Поднять DOSBox-стенд (конфиг $env:TEMP\dosbox_golden.conf, C:\GOLDEN_DOS,
   цепочка KEYRUS.COM→OPAL.COM→OPALA.EXE). Скрины прошлых прогонов смотри в
   capture/ — где застревали, что прошли (opala_000..018 = меню OPALA живое!).
2. Пройти до текстового экрана OPALA (CP866), загрузить демо-систему:
   разархивировать из OPAL.ARH (11990 б) через arh_probe/понятый формат
   (заголовок/оглавление LZ?) — или взять готовый .OPJ/.LBO из extracted/.
3. ВЫПОЛНИТЬ расчёт (прогон лучей) и ВЫГРУЗИТЬ .PRN через меню печати OPALA.
4. Сравнить с эталоном RT__2236.PRN (найди: extracted/, analysis/reverse_data/).
   Совпадение формата важнее совпадения чисел (времена/даты пропускаем).
5. Рецепт: точная последовательность autoexec + клавиш (воспроизводимый
   bash/python-скрипт, положи в scripts/golden_run.md + .py).

## Остатки старого ТЗ (коротко, по остаточному принципу)
- OPAL.PSP (найти Get-ChildItem extracted -Recurse *.PSP): hex-просмотр, формат
  (PSP = Borland Profile? настройки?). .REG уже известно = настройки, не макросы.
- OPAL.ARH: формат архива — заголовок, оглавление, метод сжатия.
