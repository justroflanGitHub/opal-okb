## СУТЬ ПУНКТА
Переключатель единиц для графиков/таблиц с зрачковыми координатами:
мм (как сейчас) / дптр (диоптрии).

- Конверсия в ОДНОМ хелпере (utils): мм→дптр = 1/мм (для радиусов кривизны),
  для углов поля — град→дптр (tan-конверсия через фокусное расстояние)
- Проверь логику по OPAL-PC Л1.4 (units); физика: 1 дптр = 1/м, т.е. мм→дптр = 1000/мм
- Применить к осям графиков и заголовкам таблиц, где фигурируют зрачковые
  координаты (волновой фронт, Цернике, PSF, косое сечение — смотри что уже есть)
- UI: переключатель в меню/панели настроек (мм/дптр), состояние в одном месте
