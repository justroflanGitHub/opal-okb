# TASK_RUSSAR: Киноруссары + Инфракрасный — расхождение f'

## Контекст
scripts/lbo_verify_f.py сверяет f' из paraxial_trace с именами систем LBO.
После фикса Гидроруссаров (это НЕ баг: подводные объективы, «f=−X» = фокус в воде =
f'воздух·1.33, знак — условность каталога) остались worst-случаи:

| система | target | got | гипотеза |
|---|---|---|---|
| Киноруссар-1 (RUSSAR.LBO, 9л) | 49 | −111.02 | ? |
| Киноруссар-5а (10л) | 35 | 143.32 | ? |
| Киноруссар-10а (8л) | 28 | 109.6 | ? |
| Инфракрасный (LENS_SPC.LBO, з-л) | 44 | −208.7 | ИК-стёкла? λ большая, n из каталога? |
| Юпитер-24 (LENS.LBO, 5л) | «f'=1» | 11.53 | парсинг имени: «f'=1 2w=40 1:1.7» — реальный f'=10? имена с одиночной цифрой |

## Задача
1. **Юпитер-24 и др. с одноцифровым f'=**: посмотреть raw-имя, если в LBO реально
   «f'=1» при 1:1.7 — вероятно каталог пишет f' в ДМ (дециметрах?) или это 10/11.5.
   Сравнить с реальным Юпитер-24 (известный советский объектив 2/35? проверить).
   Если имя парсится неверно — поправить regex в lbo_verify_f.py (например
   «f'=1 » + «2w=40» может значить f'=10 утерянный 0 при cp866-конверсии).
2. **Киноруссары**: выгрузить поверхности (scripts/), сравнить с известными схемами
   (Киноруссары — шировугольники для киноп Cameras, фове-типа; публичные патенты есть).
   Проверить гипотезы:
   a) декодер путает порядок поверхностей (обратный ход?)
   b) пропущено зеркало (9-10 поверхностей — там могут быть асферики/зеркала,
      см. MIRROR_INDEXES в fileio/decode_lbo.py)
   c) ошибка в знаках R
   Инструмент: сравнить «скаттер» — посчитать f' с инвертированными знаками всех R /
   с перевёрнутым порядком — если совпадёт с target, понять что это значит.
3. **Инфракрасный (LENS_SPC.LBO)**: «з-л» = зеркально-линзовый! Проверить: есть ли
   is_reflective поверхности (MIRROR_INDEXES 0xFFFE/0xFFFF в decode). Если декодер
   не пометил зеркала — ПОЧИНИТЬ decode_lbo.py (это вернёт и 3D-отрисовку в строй).
   Знак f' у зеркально-линзовых: чётность отражений.
4. Каждый вывод — проверка на ВСЕХ систем RUSSAR.LBO + LENS_SPC.LBO (валидатором).
